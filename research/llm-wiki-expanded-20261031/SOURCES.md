# 세 영상 검토와 발표 반영

## 확인 방법

영상1 [Builder Josh·브라이언 대담](https://www.youtube.com/watch?v=t4XEda3CB3Q)은 48분47초, 영상2 [코딩알려주는누나·용담 대담](https://www.youtube.com/watch?v=vvOuhfgH02E)은 22분17초다. 내용 담당과 엔지니어링 담당이 두 영상의 한국어 자동자막 전체 2,047행을 각각 읽었다. root는 전체 시간대를 따라 추출한 70개 프레임을 13개 연속 시트로 확인하고, 중요 슬라이드와 시연 장면을 원본 크기로 추가 확인했다. [시간 표본 기록](input/video-coverage.json)

이는 전체 자막과 시간대별 화면을 대조한 조사다. 71분 영상을 연속 재생하며 음성을 전부 청취한 기록으로 소개하지 않는다. 자동자막의 인명·전문용어 오인식은 설명의 문맥과 일차 문헌으로 대조했다. 영상 설명의 챕터명과 실제 내용 시작 시각이 다른 구간은 실제 자막·화면을 기준으로 시간 링크를 정했다.

## 지난 검토에서 보강한 점

첫 영상 [07:45](https://www.youtube.com/watch?v=t4XEda3CB3Q&t=465s)에는 PC·메신저·휴대폰으로 이어지는 개인 에이전트 개념 슬라이드가, [09:15](https://www.youtube.com/watch?v=t4XEda3CB3Q&t=555s)에는 원자료→인제스트→큰 지식 관계면의 실제 개념 슬라이드가 표시된다. 밝은 크림 배경, 큰 제목, 어두운 관계면과 연결 노드의 시선 위계를 확인했다. 지난 24장판의 대표 표본은 이 구간을 놓쳐 문서 작업 화면을 주로 참고했다. 새 발표는 이 한계를 명시하고 실제 개념 슬라이드의 설명 순서를 디자인에 반영했다.

새 그래픽은 독자적으로 작성했다. 영상 속 인물·앱 캡처·원본 슬라이드·로고를 발표 자산으로 그대로 옮기지 않았다. 첫 영상의 개인 기록 방식과 두 번째 영상의 RAG 데모는 각각 발표자의 사례로 설명하며, 보편 효과 실험으로 바꾸지 않는다.

## 기술 근거와 표시

[Karpathy 고정 설계 글](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f/ac46de1ad27f92b28ac95459c782c07f6b8c964a)의 원자료·위키·규칙, ingest/query/lint, 목차·로그와 [LangChain 검색 문서](https://docs.langchain.com/oss/python/deepagents/retrieval)의 검색·Agentic RAG 구분을 대조했다. RAG에 답 저장이 불가능하다거나, 위키에 검색이 없고 특정 문서 수에서 무조건 전환해야 한다는 식의 일반화는 사용하지 않는다. 상세 근거와 팀 판단은 [엔지니어링 전체 영상 분석](engineering/FULL_VIDEO_AUDIT.md), [기술 계약](engineering/TECHNICAL_CONTRACT.md), [내용 계약](content/STORY_CONTRACT.md), [디자인 보드](design/DESIGN_BOARD.md)에 연결한다.

원본 영상·자막·프레임은 `/tmp/stage-llmwiki-video-rebuild-20261031/`와 `/tmp/stage-llmwiki-expanded-20261031/`의 로컬 조사 자료다. 저장소에는 시간 링크·직접 쓴 요약·관찰 방법·독자 제작한 예제와 그래픽을 기록한다.

## 세 번째 공동 세미나와 전문가 공동 반영

추가 영상 [브레인 트리니티·브라이언 X 김재경 「위키는 만들었는데, 뭘 하죠?」](https://www.youtube.com/watch?v=Ef4AGnSU8UE)은 86분39초다. 새 발표 전문가 두 명이 한국어 자동자막 1,955발화를 각각 처음부터 끝까지 읽었고, 기술 담당도 전체를 대조했다. root는 전체 시간대의 73개 프레임을 13개 연속 시트로 직접 확인했다. 세 영상 합계는 자동자막 4,002발화와 시간대별 화면 143개이며, 연속 음성 청취를 완주한 기록과 구별한다. 원영상 [38:17](https://www.youtube.com/watch?v=Ef4AGnSU8UE&t=2297s)에서는 직전 수집한 두 글이 아직 답에 반영되지 않았다고 말한다. [82:19~82:40](https://www.youtube.com/watch?v=Ef4AGnSU8UE&t=4939s)에는 문서 혼선과 사전 제작된 PDF·슬라이드가 설명된다. 이를 ‘10분 동안 전체 결과물을 실시간 자동 완성했다’는 근거로 사용하지 않는다. 60% 자동화 발언은 개인 추정이며 성능 측정치로 사용하지 않는다. 원영상 14분대 RAG 설명의 비유도 기술 정의를 대체하지 않는다.

사용자 요청에 따라 추가 발표 전문가 팀의 두 에이전트를 모두 **`gpt-6.1-sol` / `xhigh`**로 명시 배정했다. 각각의 독립 검토 후 서로의 반론을 직접 교환해 [최종 변경 계약](sol-xhigh-team/lead/FINAL_CONTRACT.md)을 합의했다. [실제 배정 기록](sol-xhigh-team/TEAM.json). 기존 엔지니어링·디자인·내용 담당은 이 동일 모델 팀으로 소급 분류하지 않는다.

공동 계약은 48장·본편35분·Q&A5분을 유지하면서 세 영상의 읽기 메모를 하나의 예제로 통일한다. 마지막에는 준비된 읽기 팩에서 두 메모를 선택하는 [실제 15분 활동안](../../talks/llm-wiki/materials/session-plan.md)을 제공한다. 시간 배분·출처·연결·작성 주체를 대조할 수 있는 문서이며, 실제 모임·모델 실행 시간·학습 효과를 측정한 결과는 아니다. 개인 5겹 기록과 기간별 회고의 상세는 학습서에 보존한다.
