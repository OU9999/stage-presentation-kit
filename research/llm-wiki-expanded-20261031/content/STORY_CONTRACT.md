## 원자료와 작성 주체

- 초기 입력: `raw/brian-video.md`, `raw/yongdam-video.md`, `raw/seminar-video.md` 세 메모
- 입력은 실제 영상 원문과 위치를 요약한 발표팀의 읽기 메모. 영상 자막 전문과 별개
- 원문 요지·사람의 선택 이유/관찰·종합을 구별. 팩의 이유·위키·결과는 발표팀 작성 구성 예
- 사람의 세 행동: 쓸 목적 정하기 / 내 이유·판단 직접 적기 / 종합을 근거와 대조하고 고치기
- 영상 속 캡처 이유 질문은 발표자가 직접 만든 개인화한 스킬. 모든 도구의 표준 자동 기능으로 소개하지 않음
- 새 `raw/study-retro.md`는 실제 스터디 성과가 아닌 다음 모임의 가상 조건

## 위키의 고정 경로와 갱신

- `rules.md`: 목적·원자료 보존·작성 주체/근거 구별·관련 쪽 갱신·질문 재읽기·검토
- `wiki/sources/`: 세 원자료의 자료별 요약
- `wiki/concepts/llm-wiki.md`, `retrieval.md`: 공통 주제와 관련 근거
- `wiki/comparisons/rag-vs-wiki.md`: 같은 질문과 공통 기준의 비교
- `wiki/syntheses/study-plan.md`: 사람 목적과 알려진 조건을 반영한 현재 첫 시도 계획
- `wiki/questions/first-study.md`: 새 조건 이후 관련 쪽을 읽고 검토해 남긴 답, 실제 진행안의 근거
- `wiki/outputs/study-session-plan.md`: 실제 사람이 읽고 쓸 한 쪽 결과
- `wiki/reviews/study-session-plan.md`: 시간·원문/작성 주체·링크 대조와 남은 확인
- `wiki/index.md`, `log.md`: 결과·검토·후속 질문의 입구와 변경 이유

새 조건은 개념의 보편 정의를 뒤집지 않는다. ‘우리 적용 범위’, 비교의 ‘선택 기준’, 계획의 ‘활동/시간’을 보완하고 관련 질문·목차·로그를 검토한다. 34장 린트는 ‘예전 초안이 남아 있다면’이라는 조건부 예로 31장의 갱신을 되돌리는 인상을 피한다.

## 실제 15분 활동안

제목은 「입문자와 함께 읽는 15분 LLM Wiki 활동」. 실제 등록 문서는 `materials/session-plan.md`이며 40·41장에서 읽기 링크로 이동한다. 팩의 출력 문서와 이 등록 문서의 활동안 본문은 같다.

- 대상과 범위: 입문자가 사전 준비된 공개 읽기 팩에서 연결과 근거를 따라 읽는 활동
- 전체 입력 셋 중 선택 읽기 둘: `brian-video.md`(목적·연결), `seminar-video.md`(사람 입력·산출·검토)
- `yongdam-video.md`는 RAG 비교의 공통 근거로 유지
- 0~2분 목적 / 2~6분 선택한 두 메모 읽기 / 6~11분 관계의 근거 / 11~15분 후속 질문·남은 확인
- 2+4+5+4=15분, 실제 경과를 측정한 결과 아님
- 설치·계정 연결·모델의 위키 전체 생성 완료 시간 약속 아님
- 확인 범위: 배분 합계·선택 메모와 이유·원문 위치·작성 주체·문서/팩 링크
- 아직 확인하지 않은 것: 실제 모임 운영·입문자 이해·학습 효과·개인 모델 실행·음성 낭독

37~41장은 40/45/50/55/45초로 합계 235초다. 상세 개인 5겹 기록·기간별 회고는 학습서에서 보존한다.

## 표현과 사실 경계

- RAG와 Wiki는 같은 세 입력과 같은 질문. 임의의 좋은 답/나쁜 답으로 우열을 연출하지 않음
- 관계·요약을 미리 만드는 RAG 구현, 위키의 검색·에이전틱 탐색·모델 조정의 병행 가능성 보존
- 자료 선별 비유는 22장 한 번. 골드 데이터는 정답 인증·성능 보장이라는 기술 규격 아님
- 새 영상의 직전 자료 미반영·사전 제작 정정을 보존. 짧은 라이브 동안 전체 자동 완성했다는 주장 금지
- 역할별 작업자는 공통 근거와 사람 기준을 읽는 역할 분담. 봇 수·실제 유명인·인간 전문가 참여를 효능 근거로 쓰지 않음
- 대본은 실제 말할 설명과 예제 읽기·전환을 갖추고, 실행/성과 경계는 도입과 필요한 전환에서 명확히 표시
- paper 테마·크림/네이비/틸/코랄과 의미색 유지. 모든 그림 contain, 원문 이미지를 복제하지 않은 독자 시각화
