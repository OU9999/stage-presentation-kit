# QA 수정본 반복 모의검토 취합

A(스터디 학습자)와 B(실무 적용 참석자)는 ‘개념·비교·잠정 종합을 파일로 갱신하고 다음 질문에서 실제 다시 읽는다’는 중심을 각각 자기말로 회상했다. 원리→세 사례→검색·오류·유지 부담→자기 질문→시작 요청의 흐름은 유지됐다. **기존 우선 문제인10·16장의 공개 순서와39장의 비교 가독성은 현재 화면·정확 발언에서 해소**된 것으로 판단한다. 현재 확인 범위에서 새 차단이나 추가 제품 수정 요구는 없다. 전체 승인·실제 청중 이해·시간 적합성·도입 효과 판정은 아니다.

검정 바탕·밝은 글자, 파랑/초록/보라/주황 강조와1·26장 사진은 유지됐다.39장의 파스텔 색 면적은 줄었지만 비교 가독성 이점이 있고 전체 사진·컬러 리듬을 잃었다고 보지 않았다. 현재 PNG에서 확정 잘림·글자 부재는 발견하지 못했다. 작은 캡션을 덜 주목한 반응과 실제 누락을 구별했다.

## 미해결·새 비용·실제 관점 차이

FIRST 때 남았던 최소 입력·규칙·읽은 파일 확인 질문은 목적지 확인으로 일부 풀렸다. workshop 기본2~4에 raw·기존/갱신 위키·새 회의·질문 답의 실제 문장이 있고 기본4는 답 전에 읽은 파일을 적도록 한다. starter는 원자료 보존, 수정 전 diff·이유, 지원/해석·검토 상태, 읽은 파일·미지원 부분을 요청한다. study-guide §12에는 후보별 검토 질문/가능 조치 표와 위치·이유·근거·조치 프롬프트가 있다. 따라서 **안내 부재**로 판정하지 않고 본문 증량도 필수로 요구하지 않는다.

도구별 설치·권한 설정·경로 생성·실패 처리·복구, 자기보고와 실제 도구 기록·본문의 대조 성공, 검색 누락·Lint 탐지·검토 비용은 미검증이다. 이미 파일 에이전트를 쓰는 사람이 작은 시도를 구성할 문서 경로는 있으나 독립 첫 실행 성공을 보장하지 않는다. 종이/직접 편집 결과도 실제 LLM 실행과 구별해야 한다.

직접 왕복 회의에서 다음에 동의했다.

- **3→13:** 예고가 새 발견 여지를 줄이지만 초반 구체성 이점이 크다.13장은 배운 구분을 짧게 적용·확인하는 질문으로 현재 문구를 유지하고 추가 수정은 요구하지 않는다. 무유도 판단 실험이 아니다.
- **27:** 가운데 안내가 늘어 밀도가 높아졌으나 현재 PNG를 읽을 수 있고 대본이 기본2~4→starter→읽은 파일만 짚는다. 모든 링크를 열지 않는 진행을 유지하며 추가 축약은 요구하지 않는 후순위 관찰이다.
- **36~37:** A는 운영 기록이 주제 지식보다 강해질 가능성을 느꼈고, B는 검토답/대기 구분과 선택 이유·비용 보존의 실무 효용을 보았다. 선택 심화의 관심 차이로 남긴다.19·28장의 지식 회수와37장의 ADR 필수 아님 경계가 있어 새 차단은 아니다. 준비된 승인안을 실제 LLM 탐색·판정 성공으로 세지 않는다.

A는24장에서 모델 평가 메모와 새 오류 사례로 다음 실험의 가정을 묻는 질문을, B는 상담·회의록으로 자동 내보내기 고객에게 약속할 범위와 재확인 질문을 실제 작성했다. A의 첫 환경·복구·수행 근거 관심과 B의 요구/상태/약속·Lint 판단 관심을 함께 남긴다. 다수 청중 선호는 아니다.38장의 검사 숫자를 정확도·학습성과·시간 절감으로 넓히지 않는 경계도 유지한다.
