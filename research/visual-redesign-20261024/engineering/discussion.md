현재 의견이 모인 것은 **한 파일 직접 입력·image 프레임 우회·같은 자료의 자동 핵심값/표·다른 수량 허용·XML 파서 없는 웹 경로**다. native DOM/SVG와 ECharts 어댑터의 최종 선택, 일반 visual의 최종 kind/필드명, 숫자의 화면 직접 편집 범위는 실제 시제품과 구현 배정에서 확정한다. 지금은 공통 계약을 숨기고 엔진 옵션을 사용자에게 그대로 노출하지 않는 native 경로를 우선 제안한다.

디자인 매니저는 3종 프로토타입을 직접 작성했고 리서치 매니저는 다른 도메인 재사용 사례와 기존 제약의 실행 결과를 작성했다. 엔지니어링 매니저는 코드 감사·[계약 제안](contract-proposal.md)·[실제 기존 제약](legacy-constraints.json)을 작성했다. 이 문서는 토론의 근거이며 현재 목표·담당자·미완료 작업·최종 결정은 루트 WORK_LOG.md에 기록한다. 실무자는 이 단계에 생성하지 않았고 제품 파일·Git은 수정하지 않았다.
