# 리서치 매니저 최종 인수

2026-10-24 · `/root/research_manager`

**수치·재사용·최소 문맥에 이견 없음.** 기존 두 실무자를 실제 재개했고 각자의 검수 문서와 [최종 취합](final-review.md)을 읽었다. 데이터 담당은 [독립 계산·렌더러 검수](data-review.md) 13개 그룹을, 스토리 담당은 [저장소 밖 실제 복사·배열 변경](reuse-review.md)을 수행했다. 두 실무자가 서로의 다른 주제 입력을 직접 대조하고 편집을 종료했음을 확인했다.

매니저는 최종 `content.js`·공통 모델·렌더러·스타터와 안내를 별도로 읽었다. 이전 12주/4분류/특정 도메인을 강제하던 생성 경로 대신, 한 장의 `visual` 설정으로 자료를 선택한다. portable 폴더의 `content.js` 한 파일을 바꾸는 검수와 독립 한 장짜리 발표 성공이 초기 [재사용 목표](reuse-cases.md)를 충족한다. 350줄과 23줄이라는 형식상 길이 차이만으로 편의성을 판단하지 않고 변경 파일 수·입력 도메인·실제 실행을 근거로 삼았다.

현재 [2장 PNG](../evidence/slides/02.png), [추세](../evidence/after-trend.png), [좌표 도식](../evidence/after-matrix.png)을 직접 열어 사진용 외곽 패널 없이 메시지·큰 값·plot이 같은 무대에 배치된 것을 확인했다. 2장의 측정명 누락은 양 실무자의 공통 발견이었고, 총괄이 ‘가입 후 7일 내 첫 공유율’로 교정한 원본·PNG를 매니저도 직접 확인했다. portable 표의 탭 제목 동기화는 총괄이 `direct-deck.cjs`와 최종 HTML에 반영했고 해당 코드를 읽었다. 표의 값이나 계산 경로를 바꾸는 교정은 아니다.

실제 복사 실행 시의 `visual.js`는 `cfd2c7512538`, 최종 제품은 `02e26db1c3cc`다. 차이는 매니저·실무가 전달받고 확인한 matrix 리더 라벨 배치의 추가 후보다. 실무의 line/composition/flow 입력·계산·표 검수를 최종 제품의 모든 시각 상태를 다시 실행한 것으로 확대하지 않는다.

제품·WORK_LOG·PDF·새 테스트 파일은 수정하지 않았다. 브라우저 검수는 스토리 담당의 TaskSpace 9 p5에서만 수행했고 본인 생성 탭을 닫았다. 매니저는 브라우저를 조작하지 않았다. 실제 편집/저장/내보내기·모바일·발표자 연결과 최종 시각 QA는 총괄 및 엔지니어링의 별도 근거를 따른다.
