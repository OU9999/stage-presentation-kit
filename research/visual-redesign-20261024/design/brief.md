# 웹 발표를 위한 시각자료 재설계

차트를 이미지 패널 안에 넣는 구성을 끝내고 **메시지·핵심 값·plot을 같은 무대에서 조립한다.** 현재 12장의 수치와 이야기는 재료로 사용하되 기존 image 배치나 PDF 목적을 유지 기준으로 삼지 않는다.

## 현재 화면의 문제

`.layout-image .slide-body`의 제목/프레임/캡션 수직 구조, `.media-frame`의 border·배경, SVG의 불투명 전체 배경과 고정 1280×640 비율이 겹친다. plot 내부 색면까지 더해져 작은 그림을 큰 상자에 넣은 인상이 된다. [기존 추세](../../visual-story-20261024/evidence/slides/04.png)·[우선순위](../../visual-story-20261024/evidence/slides/08.png)·[투입](../../visual-story-20261024/evidence/slides/10.png)에서 이 구조를 확인했다. 테두리 한 줄만 지워도 제목·숫자·그림의 분리와 같은 구도의 반복은 남는다.

## 직접 작성한 세 구도

[실제 HTML 프로토타입](prototype.html)은 제품 `data.json`에서 복사한 디자인 스냅샷 [data.js](data.js)를 읽어 같은 값을 계산한다. 제품 코드·원고를 바꾸지 않은 공동 방향 검토용이다.

| 대표 | 무대 구성 | 바꾼 위계 |
| --- | --- | --- |
| [추세](evidence/trend.png) | wide: 왼쪽 큰 문장, 오른쪽 focus 값, 아래 무대 폭의 투명 line plot | 최신 58%를 native 텍스트로 크게. 축·기간은 최소화하고 모든 12점은 유지. 배경 색면/외곽 프레임 없음. |
| [퍼널](evidence/funnel.png) | split: 왼쪽 마지막 공유 인원, 오른쪽 native 단계·비교 막대 | 660명과 마지막 단계를 주역으로 둠. 그림 안 제목·표 형태의 중복 설명을 없애고 같은 가입 분모를 한 번 표시. |
| [우선순위](evidence/matrix.png) | wide: 큰 질문과 열린 좌표면, 각 점의 직접 이름 | 번호를 찾아 오른쪽 목록과 왕복하지 않음. 라벨 충돌 시 리더선 사용. 위·오른쪽 외곽선 없이 필요한 축만 남김. |

외부 폰트·라이브러리·이미지 없이 native HTML과 inline SVG를 섞는다. 막대·점·필요한 축처럼 의미가 있는 도형은 유지하고 장식용 패널·카드·그림 배경은 추가하지 않는다. 1440px에서 세 구도 모두 `.media-frame` 0, SVG 배경 rect 0, native/SVG 텍스트 경계 이탈 0이었다. [브라우저 근거](evidence/browser-review.json).

## 8종에 적용할 공통 방향

최종 데이터 계약은 엔지니어링의 [contract-proposal.md](../engineering/contract-proposal.md)를 따른다. 다음은 kind 이름과 독립적인 시각 역할이다.

| 표현 | 기본 구도 | focus·정보 배치 |
| --- | --- | --- |
| 선 추세 | wide | 단일 focus 값 자동 도출, 넓은 선, 선택된 끝점/구간. |
| 단계 퍼널 | split | 마지막 또는 선택 단계의 값, 비교 막대·직접 라벨. |
| 비교 막대 | split 또는 wide | 선택된 대상 한 곳에 의미색, 긴 이름은 native 줄바꿈. |
| 구성비 | wide | 주요 분류와 합계/분모, 실제 길이와 직접 범례. 작은 조각의 내부 글씨 강제 금지. |
| 흐름 | wide | 텍스트·연결 순서가 주역. 노드마다 상자를 씌우지 않으며 모바일에서 세로로 연결. |
| 좌표/우선순위 | wide | 직접 이름 또는 필요할 때만 리더선/외곽 목록. 복수 focus는 라벨 강조이며 합계 추정 없음. |
| 일정 | wide | native 과업명과 가벼운 레인, 실제 기간 길이. 과업 수를 고정하지 않음. |
| 투입/히트맵 | wide | 셀은 데이터를 나타내는 도형으로 유지. 읽을 수 있는 값·단위·범례를 두고 외곽 패널은 없음. |

`composition: wide | split`, `emphasis: focus`는 작은 선택지로 두고 미지정도 완성 화면이 되게 한다. focus 숫자를 별도 summary 필드에 다시 손입력하게 하지 않는다. 제목·문장은 기존 native 편집을 유지하고 숫자·라벨을 바꾸면 그림과 읽기 표가 같은 데이터에서 함께 바뀌어야 한다.

정확히 12주·4범주·3역할은 데이터 계약에서 제거한다. 7개 추세점, 5개 분류, 2·5개 흐름, 긴 라벨에서도 배열 길이에 맞춰 조립한다. 복잡해지면 작성자에게 분리/강조를 안내하되 정상 데이터를 그림 크기의 예외로 반려하지 않는다.

## 무대 문맥과 모바일

장마다 현재 결론의 **단위·비교 기간·분모 성격**만 즉시 남긴다. 가상 여부는 덱 공통 footer로 일관 표시하고 정확한 W13·표본 선정·반올림·모든 값·인과 설명은 읽기 표와 노트로 내린다. 현재 활성화율의 0–100 축은 이 예제의 디자인 선택이며 모든 시계열의 validator 규칙이 아니다.

390px에서는 같은 비율로 축소한 무대 대신 제목·큰 값·native 행을 재배치한다. 프로토타입은 세 장면을 문서 순서로 보여주고 16px의 실제 HTML 표를 펼친다. [모바일](evidence/mobile.png)에서 본문 가로 넘침 0·표 3개를 확인했다. 작은 SVG 축 글씨까지 읽기 좋다고 주장하지 않으며 각 장의 `수치 보기`에서 같은 원본 표로 이동한다.

이번 초기 검수에는 PDF·인쇄를 사용하지 않았다. 이후 실제 제품은 8종의 서로 다른 구도, 다른 수량/긴 라벨, 편집·내보내기·다른 주제 스타터를 웹에서 확인한다.
