# LLM Wiki DevDay 스타일 복원

기존48장 개편이 원고의 기본을 `theme: paper`로 바꾸고19SVG에 크림 전체 배경·큰 네이비 관계면을 넣어, 저장소의 기본 DevDay Stage 방향을 대체했다. 렌더러의 테마 적용 오류는 아니었다.

사용자 지정 `gpt-6.1-sol / xhigh` 디자인2명과 발표 전문가2명을 실제 배정했다. [TEAM.json](TEAM.json)에 모델·역할을, 각 팀의 보고서에 직접 본 범위와 상호 반론/승인을 기록했다.

## 반영한 변경

- Stage 검정 무대·큰 선언·열린 비교·관계도와 읽을 문서의 역할을 구분했다.19SVG의 바탕과 의미색을 새로 정리하고, 실제 문서의 밝은 면과 글자 대비를 보존했다.
- 재사용 가능한 editorial `variant: centered`를 추가했다. 기본 editorial과 읽기 원순서는 유지하며, 선택한 비교열만 공통 제목 기준선과 중앙 배치로 표현한다.
- 발표·배포 학습자료·활성 예제팩의 직접YouTube링크와 영상 중심 소개를 제거했다. 예제 입력을 목적/맥락·검색/비교·지식 활용의 자작 주제 메모로 재작성하고 기술 기원의 일차 근거와 내부 연구 이력은 보존했다.
- 제작 실습을 추가하지 않았다. 기존 읽기 활동의 범위와 준비된 문서/자기 노트의 시점을 구별했다.
