## 핵심 결론

발표의 공통 바탕은 **짙은 무채색 배경, 백색 타이포그래피, 넓은 여백, 장면마다 명확한 시각적 중심**이다. 초록색은 일부 캐릭터·상태·가격 항목에 사용된 여러 강조색 중 하나다. 초록색 전체 배경이나 일관된 초록 장식으로 일반화할 근거가 없다.

더 중요한 특징은 **정보량의 리듬**이다. 한 단어나 한 문장만 보이는 장면, 한 개의 비교 도표, 도해, 실제 앱 전체 화면이 번갈아 나온다. 모든 슬라이드가 같은 카드형 레이아웃으로 반복되지 않는다. 발표자의 설명을 적은 문장으로 지원하고, 시연에서는 실제 결과물이 화면의 주인공이 된다.

## 연속 구성과 전환에서 배울 점

### 키노트: 근거 → 의미 → 제품명 → 비교 증거

19:30의 형상 중심 장면에서 20:00의 제품명·단일 도표로 이동한다. 20:30에는 짧은 선언으로 정보량을 낮추고, 21:00에는 기능명과 두 줄의 보충 정보만 남긴다. 21:05에는 같은 작업을 두 환경에서 비교하는 화면으로 증거를 보여준다. 이 순서와 프레임은 실제 영상에서 확인했다. 20:20–21:05는 별도로 연속 재생했고, 마지막 비교 화면의 재생 상태도 관찰했다.

[20:35에는 문자가 사라진 별 배경](evidence/devday/keynote-20m35-playing.png), [20:50에는 발표자 클로즈업](evidence/devday/keynote-20m50-playing.png)이 보였다. 따라서 방송의 얼굴 클로즈업을 슬라이드 디자인으로 분석하거나, 샘플 시점 사이의 정확한 애니메이션 지속 시간을 단정하면 안 된다. 원본 슬라이드 전환 방식의 세부 easing·duration·제작 도구는 확인하지 못했다.

템플릿에서는 **한 개의 단순한 도표 → 한 줄의 의미 → 짧은 이름과 설명 → 결과 비교**를 네 장의 재사용 가능한 연속 예제로 제공할 수 있다. 원본의 제품명·수치·캐릭터를 복제할 필요는 없다.

### Codex 세션: 변화 설명 → 문제의 크기 → 해결 구조 → 실제 앱

01:30에는 적은 에이전트와 많은 동시 작업을 비교한다. 02:00에는 길어지는 작업 시간을 하나의 시간축으로, 02:30에는 직접 관리해야 하는 기기와 운영 부담을 세 항목으로 보여준다. 03:30에는 여러 접점을 공유하는 중심 구조를 제시하고, 04:00부터 실제 앱으로 들어간다. 이 구간은 여러 타임코드의 **seek 프레임으로 구성 순서를 확인**했으며 전체를 연속 재생한 것으로 보고하지 않는다.

여기서 옮길 것은 검은 화면에 예쁜 글자를 얹는 표면보다, **청중이 이해해야 할 한 단계씩을 다른 레이아웃으로 분리하는 순서**다.

## 재사용 템플릿에 적용할 제안

아래는 관찰로부터 도출한 디자인 판단이며, OpenAI의 공식 규칙이나 원본 제작 사양이 아니다.

1. **기본 팔레트:** 차콜/백색을 주축으로 한다. 밝은 종이색 테마도 선택지로 둘 수 있다. 초록색 전체 배경과 반복적인 초록 포인트는 기본값에서 제거한다.
2. **강조색:** 한 장에 한 개의 강조 목적을 먼저 정한다. 비교 계열이나 의미 구분이 있을 때만 여러 색을 쓴다. 장식용 색 띠·고정 색상 뱃지를 모든 장에 반복하지 않는다.
3. **타이포그래피:** 한 문장 슬라이드와 증거 슬라이드의 정보량 차이가 눈에 보여야 한다. 16:9 템플릿의 시작값으로 큰 선언 96–140px, 일반 제목 56–72px, 핵심 본문 28–40px 정도를 검토할 수 있다. 이는 실측값이 아닌 구현 제안이다.
4. **양식:** 선언, 제품/개념명, 하나의 도표, 두 결과 비교, 관계 도해, 한 인용문, 실제 미디어/데모 양식이 우선이다. 양식을 카드 개수로만 구분하지 않는다.
5. **시연:** 화면 대부분을 실제 이미지·영상·브라우저 결과에 배정한다. 설명은 진입 직전 한 장과 발표자 노트에 둔다. 시연 창 옆에 동일한 설명을 길게 반복하지 않는다.
6. **전환:** 기본은 빠른 cut 또는 짧은 fade. 의미를 순차적으로 드러낼 때만 단계 공개를 사용한다. 원본의 별 애니메이션을 모든 장의 반복 효과로 일반화하지 않는다.
7. **편집 편의:** 사용자가 제목·짧은 문장·도표 데이터·미디어만 바꿔도 구성 질서가 유지되어야 한다. 레이아웃별 권장 글자 수는 예시 옆의 도움말과 노트로 안내한다.
8. **확인되지 않은 것:** 원본이 웹 기반으로 제작되었는지, 어떤 슬라이드 프로그램을 사용했는지 확인하지 못했다. 영상의 세련됨을 웹 제작 방식의 우월성 증거로 취급하지 않는다.
