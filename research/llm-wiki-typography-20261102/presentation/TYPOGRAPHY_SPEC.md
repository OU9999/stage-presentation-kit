## 공통 조판의 실행 계약

1. **필수 의미와 메타를 먼저 분리한다.** 기억할 주장, 질문에 답하는 관계, 책임/조건/한계는 본문이다. 파일 출처·탐색 링크·부가 메타와 구분한다. ‘보조’라는 이름으로 필수 내용을 작게 보내지 않는다. 17/18 책임 설명과20 비실측 한계는 화면에서 읽을 대상이다.
2. **1600×900 논리 캔버스의 역할별 기본값을 고친다.** 안전영역x92..1508/y78..830을 출발점으로 유지한다. 정보형 제목·몸체 기점과 표/열의 기준선을 역할군 안에서 안정시키며 선언형17/18·표지·전체 미디어는 다르게 놓을 수 있다. 필수본문/관계라벨은32–36logicalpx을 설계 출발점으로 검토하고 출처·메타22–24와 구별한다. 모든 장과 미래 발표에 하나의 숫자를 강제하지 않는다.
3. **실제 표시 크기를 보고한다.** native text는 computed font-size×stage scale, SVG는 내부 font-size×논리캔버스 안의 contain 배율×stage scale를 대조한다. contain 배율은 논리배치 이미지크기와 SVG viewBox의 비로 계산하고 이미 변환된 실제pixel크기에 stage scale를 다시 곱하지 않는다. 새1280의actualstage917.333에서배율은0.573333이므로32–36logicalpx는18.347–20.64표시px다. viewport1280전체를stage폭으로환산하지않는다. SVG 원본32만 보고 native32와 같은 크기라고 말하지 않는다. 남는 공간은 제목 중복·문장 구조·그룹 폭을 정리해 읽을 정보에 배분한다.
4. **행은 의미구로 만든다.** 목적어/부사구와 서술어를 함께 읽고, 조사만 다음 줄로 보내지 않는다. 2/3열 유지가 타당하면 폭·거터·강조·의도 개행으로 해결한다. 짧은 독립 주장, 단계 라벨, 수치/단위가 짧은 행이라는 이유로 실패하지는 않는다.
5. **의도 개행과 지원 문법을 구별한다.** A의 실제 parser 확인에서 본문/인용의 줄끝 backslash는 AST `br`, 일반 개행은 soft break다. H1 끝backslash+다음줄은 제목br이 아니라 literal backslash와 별도p이므로 권장하지 않는다. 제목은 기존 지원으로 충분한지 먼저 확인한다. 새 제목 개행 계약이 필요하면 엔지니어가 명시 입력·AST·렌더·읽기·편집/내보내기·생성/인쇄 정합성을 함께 검증한다. 모든 soft break를 전역 hard break로 바꾸지 않는다.
6. **공통 내용은 공통 소속이어야 한다.** 6장의 공통p는 기존 지원되는 두H2 앞 전폭p를 우선 검증할 수 있다. 이는 의도한 원고 순서 변경으로 명시하고 읽기·대본도 확인한다. 새 구문이 꼭 필요한지 검증 전 발명하지 않는다. CSS로 AI열 안의 문장만 중앙에 그려 공통 소속인 것처럼 보이는 해법은 불충분하다.
7. **기본값과 개별 예외를 분리한다.** document의 표/질문 예시, centered editorial의 설명, media의 핵심설명과 자료링크는 재사용 역할을 기준으로 고친다. 특정slide id나 한국어 문구별 CSS 보정은 예방책이 아니다. 모든3열·밝은자료·반복구도를 금지하지 않는다.

실제 본문 개행 예시:

```md
> 왜 골랐고,\
> **어떤 질문을 풀려는가?**

> 목적과 내 판단은\
> **내가 적습니다.**
```

입력에 `br`이 생기는 것과 실제 독해 성공은 별도다. 두 발표 크기에서 추가 자동개행·강조 분리·편집 손실을 확인한다. 한국어 운영체제 글꼴에 따라 달라질 수 있는 한계도 기록한다.

## 5·11·20 검정 재설계의 세부 수용

- **5**: raw는 원자료 보존, wiki는 해석/정리/갱신 대상, rules는 두영역의 약속임을 표면색 없이 읽는다. raw파일3개, 요지/선택이유/남은질문, wiki의 개념·비교종합·질문목차로그, 규칙4항목을 모두 남긴다. 원자료가 wiki로 변환되어 사라지거나 rules가 wiki의 하위문서처럼 보이면 실패다.
- **11**: 일반비교축 ‘한자료요약/여러자료개념’이 예시주제명보다 먼저 읽혀야 한다. 예문과 context-note.md, 목적과맥락/검색과비교/지식의활용 근거, RAG와위키비교/현재계획 연결을 남긴다. 두 흰카드를 검정카드로 반전한 뒤 같은 작은글자/다층위계를 남기면 미해결이다.
- **20**: 0~2분 질문정하기,2~6분 두메모확인,6~11분 원자료→개념→비교 한관계읽기,11~15분 후속질문과확인기록의 시간열/활동기준선이 대응한다. 목표와 관계행을 먼저 읽고 자작메모팩(목적과맥락+지식의활용), 발췌/시간배분예시, 실제운영·학습효과·설치/모델생성시간 실측아님을 화면에서 읽는다. 정체성/한계가 링크에만 있으면 실패다.

외부 사진·UI·문서의 고유색을 지키는 반례는 계속 남긴다. 검정화는 지정된 자체제작 자산의 재조판이며 SVG색 전역치환·회색조 필터가 아니다.
