# EX-BOOK — 가상 소설 독서의 입력과 전후 파일

모든 문장은 발표팀이 만든 구성 예다. 실재 소설·인물·모델 실행 결과가 아니다. 아래 파일 이름은 구성 위키의 상대 경로이며 이 문서의 코드블록에 전후 내용을 보존한다. LLM이 어느 파일을 읽고 쓸지 설명하는 fixture다.

## 입력1 · raw/ch01-notes.md

```markdown
# 가상 소설 1장 독서메모
- 읽은 범위: 1장만
- 서술된 행동: 서하는 지도를 숨긴 뒤 북문을 떠났다.
- 다른 인물의 말: 도윤은 “우리를 버렸다”고 말했다.
- 아직 모름: 서하가 지도를 숨긴 이유
```

## 이전 위키 · wiki/characters/seoha.md

```markdown
# 서하
1장에서 지도를 숨기고 북문을 떠난다.
도윤은 이를 버림받은 행동으로 받아들인다.
서하의 의도는 아직 확인하지 못했다.
근거: raw/ch01-notes.md
연결: places/north-gate.md, themes/trust.md
```

## 새 입력 · raw/ch03-notes.md

```markdown
# 가상 소설 3장 독서메모
- 읽은 범위: 3장까지
- 서술된 정보: 지도에는 추적 장치가 있었다.
- 서하의 말: 동료를 피신시키려고 지도를 감췄다.
- 주의: 서하의 설명이 모두 사실인지는 뒤 장에서 더 확인해야 한다.
```

## 갱신 위키 · wiki/characters/seoha.md

```markdown
# 서하
1장에서 지도를 숨기고 북문을 떠난다.
3장에서 지도에 추적 장치가 있었음이 드러난다.
서하는 동료를 피신시키려 했다고 설명한다.
해석: 도윤이 느낀 배신과 서하가 밝힌 목적은 구별할 필요가 있다.
미확인: 서하의 설명 전체와 이후 선택
근거: raw/ch01-notes.md, raw/ch03-notes.md
연결: themes/trust.md, sources/ch03.md
```

함께 갱신할 파일: `sources/ch03.md`(장 요약), `themes/trust.md`(관점별 해석), `index.md`(찾을 입구), `log.md`(3장으로 동기 해석을 수정한 이유). 기존1장 메모는 보존한다.

## 후속 질문과 다시 쓸 파일

“서하의 선택을 왜 배신으로만 볼 수 없을까?” → index/인물/신뢰 주제/1·3장 메모를 읽는다. 다음은 유용한 답을 저장한다고 가정한 산출물이다. 이 생성·저장은 실행하지 않았다.

```markdown
# wiki/questions/seoha-and-trust.md
1장의 도윤은 버림받았다고 판단한다. 3장의 서하는 동료 보호가 목적이었다고 말한다.
해석: 같은 행동을 보는 관점과 나중에 알려진 설명이 다르므로 배신으로만 단정하기 어렵다.
경계: 서하의 말 전체가 사실인지, 이후 선택이 같은 목적을 따르는지는 미확인이다.
읽은 범위: 3장까지
연결: characters/seoha.md, themes/trust.md
근거: raw/ch01-notes.md, raw/ch03-notes.md
다음 질문: 서하의 이후 행동은 이 설명과 일치하는가?
```

이 답은 인물·신뢰 페이지에 역방향으로 연결한다. 다음 장을 읽을 때 답의 마지막 질문이 탐색의 출발점이 된다. 줄거리 사실과 등장인물의 말, 독자의 종합 해석을 한 종류로 합치지 않는다.
