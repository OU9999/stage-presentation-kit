## 실제 산출물과 판정

`talks/llm-wiki/materials/`의 5개 Markdown을 전문 읽고 인수했다. 기존 발표의 읽기 모드나 txt를 늘리는 대신 별도의 학습 경로를 제공하므로, 독립 공부 자료·대본·정보 모음이 부족했다는 새 요구의 **콘텐츠 범위는 충족**한다. 웹 조판과 실제 화면, 개편 후 발표 대응은 다음 팀의 검증 범위다.

- `index.md`: 네 자료의 역할, 혼자 공부하는 순서와 발표 복귀.
- `study-guide.md`: 24,114자. 원자료/주장/근거/해석/결정, 3층과 ingest/query/lint, 실제 읽기 메모에서 개념·비교·질문 답으로 이어지는 파일 예제, 연결도 양방향 읽기, 수정 diff, index/log, 결정, 충돌·최신성·삭제·대체, 운영 부담, 카드/프롬프트, FAQ 6개와 자가점검 6개 해설.
- `speaker-script.md`: 현재 12장 대응, 실제 발화·청중 질문·진행·전환·예상 Q&A 8개. 18분+2분은 리허설 전 배분안이며 실측이 아니다.
- `reference-library.md`: 6개 1차 자료마다 읽는 이유·읽을 절·지원 주장·한계·읽은 뒤 남길 기록, 용어와 후속 학습 경로.
- `workshop.md`: 11,691자. 원문 입력, 읽기 메모 2개, 개념 2개와 비교, 질문 답 저장, 새 근거에 따른 diff, 결정/index/log, 오류 6개 해설과 추가 도전. 기본 단계 시간 합계는 최소 20분/최대 30분이며 실제 학습자 측정은 아니다.

분량은 관측값이며 완료 기준은 아니다. 독자가 작동 구조를 설명하고 실제 예제를 고칠 수 있는지를 기준으로 읽었다. 학습서 45~60분은 원문 대조와 자가점검을 포함한 작성자 추정으로 명시했다.

## 직접 교차 검토와 교정

A는 guide/workshop, B는 대본/reference의 실질 초기 원고를 각각 작성했다. B가 A의 guide 전체를 읽고 피드백했으며 A도 B의 두 문서를 전문 읽고 직접 회신했다. B는 guide 내용을 자기 대본에 반영했다. B가 workshop을 읽었다고 보고하지 않았고, manager가 workshop 전체와 모범 해설을 독립 인수했다.

반영을 실제 확인한 교정은 guide/workshop의 순서값 2/5, diff의 중복 `+` 제거, LoRA 판 고정 링크, 질문 카드의 개념/비교 연결, workshop 비교표 세 번째 행의 모범 검토 항목이다. A의 반례에 따라 대본 9장은 원문 재접근 실패와 과거 실제 검토 이력의 보존을 구분했다.

## 형식과 링크 확인

5문서를 markdown-it/YAML로 독립 파싱했다. 각 문서 H1 1개, raw HTML 0개, 자료 order 1~5, 실제 본문 로컬 링크 58개와 Unicode/NFKC slug 대상 누락 0개, `git diff --check` 통과다. 코드 블록의 가상 위키 경로는 실제 사이트 문서 링크와 구분해 확인했다. 제품 코드·slides·assets·HTML 생성과 브라우저는 콘텐츠팀이 변경/실행하지 않았다. 낭독 시간·독자 학습 시간·도입 효과는 실측하지 않았다.

두 작성자는 실제 final/편집 종료했다. 후속 디자인 manager와 직접 메시지를 교환하고 5원문·핵심 사례·6근거·장번호 동기화 범위를 합의했으며 상대의 실물 확인과 수신 확인을 받았다. 디자인 A에 slides와 speaker-script, 다른 네 자료의 발표 장번호/복귀 링크만 이양하고 연구 설명 본문은 보존하기로 했다.

## 디자인 연결 계약

1. 화면의 주역은 실제 RAG/LoRA/Wiki 읽기 → 개념·비교 → 질문 → 원문 대조 → 검토 답 재저장 → 오류 수정 diff와 변경 이유이며, 일정 변경은 보조로 축소한다.
2. 자료의 기전 설명과 근거를 보존하고, 학습 과정·인물·기록·수정 장면은 가상 교육 예제로 표시하며 실제 운영 성과나 측정 효과처럼 묘사하지 않는다.
3. 새 발표 구조에 맞춰 대본 전체·18+2분 배분과 5문서의 발표 장번호 링크를 다시 맞춘다. 특히 reference의 기존 8/10장 링크와 workshop의 11장 링크는 개편 후 재검증한다.
