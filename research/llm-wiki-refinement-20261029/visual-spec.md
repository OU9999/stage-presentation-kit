# LLM Wiki 구현 시각 사양

기준: main d9c1b2f, 40장/자료6개와 고정 데모를 보존하는 후속 구현. senior는 주제 로컬 SVG/CREDITS와 이 문서를 소유하고, A만 slides·자료·대본을 쓴다. root가 최종 생성물과 실제 발표 PNG를 검수한다. 과거 평가 시안은 수정하거나 발표 본문 전체 이미지로 붙이지 않는다.

## 중심 비유와 개념의 대응

‘스터디 공용 노트를 함께 고쳐 다음 질문에 다시 쓴다’를 하나의 중심 비유로 쓴다. 비유를 늘리지 않고 실제 파일 역할로 돌아올 수 있게 한다.

| 친숙한 대상 | 실제 역할 | 보여줄 시각/장 | 말할 수 있는 범위 |
| --- | --- | --- | --- |

### 6장: `assets/study-notebook-map.svg` (신규)

- 역할: 비유와 실제 파일의 대응. 원자료함→함께 고친 설명쪽을 주 관계로, 작업 규칙은 두 영역 전체에 적용하는 괄호, log는 설명쪽에 연결한 별도 기록으로 그린다.
- 권장 제목: `공용 노트의 역할을 파일로 나눈다`.
- alt: `공용 스터디 노트의 원자료함은 raw, 함께 고친 설명쪽은 wiki다. 적는 약속은 원자료 보존·근거 위치·검토를 정하는 작업 규칙이고, log에는 무엇을 왜 고쳤는지 남긴다. 규칙은 변환의 다음 단계가 아니라 작업 전체에 적용한다.`
- 원본 링크: `[도식 원본 열기](./assets/study-notebook-map.svg)`.
- 대응 평문: `원자료함 raw는 보존하고, 설명쪽 wiki는 근거를 대조해 고칩니다. 작업 규칙을 전체에 적용하고 log에 바꾼 이유를 남깁니다.` 발표 본문/alt에서 같은 의미가 읽혀야 한다.
- 발언: `서가 전체를 새로 외우는 비유가 아닙니다. 공용 노트에서 원자료, 함께 고친 설명, 적는 약속, 바꾼 이유의 자리를 나눕니다. 다음 질문에서는 필요한 쪽을 다시 읽습니다.`

### 19장: `assets/reuse-route.svg` (신규)

- 역할: `고친 주장 → 첫 답 → 새 질문 → 저장 기준`의 한국어 관계를 주역으로, C1/Q1/Q2/D2는 작은 보조 식별자로 둔다. 아래 지원 기록은 index·log·이전 선택 D1·검토 대기 pending으로 분리한다. D1은 새 질문의 판단 입력, pending은 저장 기준 적용 뒤의 대기 자리다.
- alt: `고친 주장 C1을 첫 답 Q1에 반영하고, 그 설명과 이전 선택 D1을 새 질문 Q2에서 다시 읽어 저장 기준 D2를 정한다. index는 읽기 입구, log는 바꾼 이유, D1은 대체된 선택을 보존하고 pending은 근거 부족 답을 남긴다. 사람이 검토한 연결이며 자동 영향 발견이 아니다.`
- 원본 링크: `[도식 원본 열기](./assets/reuse-route.svg)`.
- 대응 평문: `고친 주장과 첫 답, 이전 선택을 새 질문에서 다시 읽습니다. 새 저장 기준과 함께 입구·변경 이유·대체된 선택·검토 대기를 남깁니다.`
- 발언: 먼저 한국어 위 흐름만 읽고, 아래 기록은 `필요하면 돌아갈 자리`라고 묶는다. 8개 이름을 외우게 하지 않는다. 실제 8쪽 내역은 31/자료로 넘긴다.

### 22장: `assets/reuse-inputs.svg` (기존 주제 도식 수정)

- 역할: 오른쪽 세 문장이 왼쪽 Q2 판단의 입력임을 화살표/`함께 읽어 판단` 라벨로 명시한다. 한국어 의미가 먼저, C1/Q1/D1은 보조 식별자다.
- alt: `새 질문 Q2는 고친 주장 C1, 첫 답 Q1, 이전 선택 D1을 함께 읽어 판단한다. 링크만으로 일반화를 지원하지 못함, 다음 답이 고친 파일을 다시 읽어야 함, 채팅에서 찾기 어려워 모든 답을 모으려 했던 이유를 저장 기준의 입력으로 쓴다. 고정 승인 예제이며 검색·생성 성능을 측정한 결과가 아니다.`
- 원본 링크는 기존 `./assets/reuse-inputs.svg` 유지.
- 대응 평문/발언: `고친 주장과 첫 답뿐 아니라, 처음 모든 답을 모으려 했던 이유도 함께 읽습니다.`

26장의 기존 `decision-transition.svg`는 관계를 그대로 두고 화면 첫 라벨만 `D1 · 대체됨`으로 한국어 우선 변경한다. 원본 상태값 superseded는 desc/실제 데모 파일에서 보존한다.

## 가독성/구현 범위

관계도 주요 한국어 역할은 38–42px, 정보 본문은 32px 이상을 우선하고 ID만 24–26px 보조로 둔다. 이 수치는 SVG 좌표계이며 실제 발표에서의 크기는 root의 PNG로 판단한다. 1200×450급 비율·기존 검은 바탕·흰/파랑/초록/보라를 유지한다. 도식은 SVG text와 title/desc, Markdown alt/평문/원본 링크의 세 경로로 의미를 제공한다.

이번 문제는 내용·기존 layout·주제 로컬 도식으로 해결한다. 공통 엔진/실시간 입력/웹 투표/자동 집계 변경은 현재 필요하지 않다. root의 최종 PNG에서 실제 가독성 근거가 나오면 좁은 자산 수정 또는 A의 내용 위계 조정부터 검토한다.
