# 실제 발표 장면 관찰

담당 `/root/design_manager/anthropic_editorial_typographer`. 관찰은 2026-10-25 공식 Anthropic YouTube 채널에서 연 실제 Code w/ Claude 세션의 아래 세 지점으로 제한한다. 홈페이지의 폰트나 색을 발표 규칙의 근거로 쓰지 않았다. 회사 내부 규칙이나 회사 경력을 주장하지 않는다.

공식 원본: [Prompting 101 | Code w/ Claude](https://www.youtube.com/watch?v=ysPbXH0LpIE), 업로더 [Anthropic](https://www.youtube.com/@anthropic-ai). 페이지 설명은 2025-05-22 샌프란시스코 Code w/ Claude 발표로 명시한다. 브라우저에서 공식 채널 검색→해당 영상→video currentTime 확인 후 일시정지 캡처했다. TaskSpace11 p3만 사용했다.
