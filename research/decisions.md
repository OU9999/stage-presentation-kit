# 실제 발표 세션에서 정한 수정 기준

2026-10-23. 발표 주제가 바뀌어도 재사용하는 템플릿을 위한 조사입니다. 행사 사이트의 색상과 히어로를 발표 슬라이드의 근거로 삼았던 첫 버전의 기준을 교체합니다.

> 추가 조사 반영: 사진·컬러 활용은 [새 비교 보드](color.html)와 [운영 기준](color-design-criteria.md)에서 확장했습니다. 아래 초기 판단의 무채색 기본은 공통 바탕에 관한 것이며, 사진 탈색이나 데이터·상태 이외 컬러의 금지를 뜻하지 않습니다. 주장 강조·발표자 소개 색면·제품 정체성도 실제 영상에서 확인했습니다.

추가 구현: [20장 예제](../index.html)에서 사진 모음·조건 비교·작품 콜라주·다중 결과·의미색·발표자 소개를 사용할 수 있습니다. [장면별 연결표](../EXAMPLES.md)에 연구 근거와 변경할 필드를 정리했습니다.

## 조사 역할과 확인 범위

- 세션 영상 탐색: OpenAI DevDay **2026** 키노트와 별도 Codex 세션의 공개 영상을 재생하고, 시간대별 프레임과 일부 연속 구간을 확인했습니다.
- 외부 사례 탐색: Apple WWDC25, Figma Config 2025, Vercel Ship 2025의 실제 발표 영상을 확인했습니다.
- 디자인: 위 근거를 재사용할 배치·밀도·색상 규칙으로 옮깁니다.
- 구현: 내용 한 파일, 설치 없는 실행, 발표자 창을 유지하며 새 양식을 반영합니다.

매니저도 보고서의 대표 장면을 직접 열어 비교했고, Codex 세션 03:52–04:04 구간을 추가 재생해 실제 UI 시연 장면을 확인했습니다. 영상 전편을 완주했다는 의미는 아닙니다. 세부 관찰 시간과 캡처는 [DevDay 보고서](devday-session-analysis.md), [외부 사례 보고서](external-presentation-analysis.md)에 기록합니다.

## 채택하지 않은 것

- 행사 로고, 캐릭터, 별 배경, 방송의 발표자 작은 화면을 그대로 복제하지 않습니다. 모두 원본의 맥락에 속합니다.
- 영상의 카메라 컷을 슬라이드 전환 애니메이션으로 해석하지 않습니다.
- 모든 발표가 검정 배경이어야 한다거나, 관찰한 발표가 웹 기술로 제작됐다고 추정하지 않습니다. 영상만으로 제작 도구는 확인할 수 없습니다.
- 새 순차 공개 엔진을 추가하기보다, 같은 구도를 복제해 다음 장에서 내용을 더하는 방식으로 재사용의 부담을 낮춥니다.

## 사용 기준

한 장에는 한 역할을 줍니다. 중앙 문장은 기억할 주장, 도표는 그 주장의 근거, 전체 미디어는 작동하는 결과를 맡습니다. 세 양식의 크기와 정보 밀도가 달라져야 흐름이 생깁니다. 나머지 비교·숫자·인용·단계 양식은 발표 내용이 요구할 때 골라 사용합니다.

초록을 다른 색으로 바꿔 반복하는 방식은 피합니다. 기본 테마는 무채색으로 두며, 실제 데이터나 제품 화면에 이미 있는 색의 의미를 우선합니다.
