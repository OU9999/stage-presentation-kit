숨겨진 장의 이미지

03

발표자 전체 갱신

장 이동에도 전체 deck을 전달하고 다시 그리는 경로가 있습니다. 내용 변경과 탐색을 나눠 갱신 범위를 줄입니다.

04

한 장의 데이터 적용

JSON 한 장을 바꿀 때 전체 검증·저장·렌더를 거칩니다. 그림·표·저장을 일치시키며 국소 갱신을 검토합니다.

개선 후보이며 절감률은 미측정입니다. 이미지 용량은 로컬 원본 합계입니다. 폴더 복사·content.js 교체·file 실행은 별도 portable 출력의 검증 조건으로 유지합니다.
