# 아시아 DevDay 화면 재검토 — 2026-10-23

담당: `/root/research_manager/asia_research`. 구현 변경 없이 원문·원본 사진과 [현재 4번 슬라이드](../current-slide-4.png), [총괄의 소스·브라우저 기준 확인](../baseline.md)을 비교했다.

**현재가 Grid라서 다른 것은 아니다.** 실제 서울·도쿄 화면도 외곽을 맞추고 내부 분할을 달리하는 구조다. 더 큰 차이는 **어떤 결과물을 어떤 크기로 보여 주는지, 자산을 담는 방식, 경계의 위계**다. 현재의 메시지 카드 두 개와 작은 문서·UI 전체 캡처가 원본의 제품 결과물·UI 기능 묶음을 대체하면서, 하나의 성과 요약보다 여러 샘플을 끼운 카드판으로 보인다. 이는 비교에 따른 디자인 판단이다.

## 사진을 다시 보니 달라진 판단

이전 [서울 조사](../../seoul-devday-visual-research-20261023.md)와 [도쿄·벵갈루루 조사](../../completed-cities-visual-research-20261023.md)의 주요 사실은 유지된다. 다만 다음 해석은 더 좁혀야 한다.

1. **“정규 격자 대신 불규칙하게 만들자”는 처방은 충분하지 않다.** 현재도 span을 가진 혼합 배치다. 원본은 외곽과 가터에 질서를 두고, 행마다 다른 하위 분할과 매체의 모양으로 변화를 준다. 임의 회전·겹침·랜덤 위치는 이 원본들에서 확인되지 않았다.
2. **“모든 항목을 같은 둥근 타일로 묶자”도 원본 감각을 온전히 설명하지 못한다.** 새 고해상 S2에서 UI 패널과 네 개 앱 아이콘은 각자의 흰 표면이 강한 자연 경계다. 이 전체 묶음을 감싸는 외부 상자의 선이 동일한 강도로 두드러지지는 않는다. 어두운 수치·제품 타일의 얇은 구조선과 매체 자체의 흰 경계를 같은 종류의 선으로 취급하면 지나치게 상자화된다.
3. **border의 색이 항목마다 다르다는 구현 버그는 확인되지 않았다.** 총괄 baseline은 모든 타일의 선이 `rgba(246,246,244,0.22)`라고 확인했다. 현재 자산의 크림·하늘색·남색 표면과 안쪽 프레임, 검정 여백이 공통선과 만나 다르게 보이는 문제를 먼저 검토해야 한다. 원본 사진에 보이는 회색·초록·노랑 기운을 그대로 템플릿 토큰으로 옮길 근거는 없다.
4. **일반 문구 카드와 제품명을 보여 주는 타이포 결과물은 역할이 다르다.** 원본의 `ChatGPT Images 2.5`는 작품처럼 만든 제품 시각물이고, 옆 제품 타일에는 행성·우주 같은 비주얼이 있다. 현재 `BUILD / 생각을 실행으로`, `CREATE / 다르게 만들어요`는 두 줄 이상 줄바꿈하는 일반 메시지로 바뀐다. 텍스트 타일 자체의 금지가 아니라 내용의 역할과 매체 밀도 차이다.

## 혼합 bento의 구도를 분해한 비교

| 시선을 잡는 큰 요소 | 우측 세로형 제품 비주얼은 이름과 시각물이 한 덩어리다. 밝은 UI·일러스트와 어두운 제품·수치가 번갈아 대비된다. | Signal 링에는 위·아래 소형 설명이 있고, 자산과 타일 비율 차이로 검정 수직 띠가 보인다. | 큰 주역 한 개가 하나의 메시지로 읽히도록 자산부터 해당 비율로 준비한다. |

| UI 묶음 | 큰 버튼/선택기와 네 개 앱 아이콘을 단순한 기능 형태로 보여 준다. | 작은 대시보드 한 화면에 미세 본문·체크리스트·작은 차트를 모두 넣는다. | UI를 통째로 축소하기보다 이야기의 핵심 상태나 기능을 확대한다. |
| 사진 | 사람·장면이 타일 면을 채운다. | 필기하는 인물과 호수가 서로 다른 맥락을 만든다. | 두 사진과 제품·수치가 같은 성과 이야기를 설명하도록 소재를 선택한다. 미관만으로 무관한 사진을 섞지 않는다. |
| 밝은 문서 | 실제 Monitoring 카드의 내용은 작은 작업 사례다. 이것과 밝은 기능 UI의 흰 면이 리듬을 만든다. | 크림색 보고서, 하늘색 패널, 남색 대시보드가 각각 자체 바깥 여백을 가진다. | 모든 밝은 면을 없애기보다 하나의 문서·하나의 기능 UI처럼 역할과 수를 정한다. |
| 경계 | 사진·일러스트는 자연 edge, 어두운 제품/수치는 얇은 중립선, UI는 자체 표면이 시각 경계를 만든다. | 모든 콘텐츠가 공통선 상자에 들어가고 contain 여백·자산 내부선이 더해진다. | 구조 경계·매체 표면·UI 내부선을 따로 설계한다. 색 교체만으로 해결하려 하지 않는다. |
| 수치 | 짧은 수치가 가장 크고 설명은 짧다. 파랑·주황·보라는 구분 역할이다. | 24·6·3이 시각적 역할은 비슷하지만 동일한 이야기의 성과인지 설명이 약하다. | 가상 수치도 무엇의 결과인지 연결하고, 한 장에서 숫자보다 작은 여러 본문을 경쟁시키지 않는다. |

## 검증과 남은 한계

- 원문 6개(공식 일정·Zenn·디지털투데이·뉴스1·서울신문·Robin Francis)의 현재 제목·날짜·행사 정체성·캡션을 확인했다. 공개 원문 추출 기록은 [evidence/asia](evidence/asia/)에 있다.
- 새로 내려받은 서울 사진 두 장은 HTTP 200, SHA-256을 [download receipts](evidence/asia/download-receipts.json)에 기록했다. S2 고해상 원본을 직접 열었고, S1은 동일 원본의 기존 로컬 파일과 시각을 대조했다.
- 직접 본 원본은 서울 5장(전체 bento·근접 bento·새 근접 고해상·아이콘월·두 수치), 도쿄 8장(bento·ranking·wireframe·manager·chart·MCP·code process·session title), 벵갈루루 수치 1장, 현재 4번 화면이다. 다른 사진을 전부 재검수했다고 주장하지 않는다.
- 아시아 세 도시의 전체 공식 영상·PDF/PPT·원본 슬라이드 파일은 **이번 재검토에서도 UNVERIFIED**다. 추가로 확보했다고 보고하지 않는다. 기사 속 녹음 정리와 사진은 전체 영상을 직접 본 것과 구분한다.
- 정확 폰트·HEX·반경·간격, 장면 전환, 슬라이드 내부 동영상의 재생 상태, 제작자 소속은 해당 원본 파일이나 녹화가 없어 확정하지 않았다.
- 제품 런타임·Markdown 예제·렌더러는 수정하지 않았다. 연구 사진은 비교 증거이며 자유 사용 예제 자산으로 옮기지 않는다. 제품 테스트·모바일·PDF 검증은 이번 조사에서 수행하지 않았다.

## 현재 제품과 제안의 인계 구분

**Current**는 [baseline](../baseline.md)과 [current-slide-4](../current-slide-4.png)에 기록된 실제 제품의 4번 슬라이드다. 준비 중인 `research/review-20261023/design/proposal.html`은 이 조사에서 도출한 **독립 디자인 시안(Proposal)**이며, 실제 DevDay 원본이나 현재 제품의 구현 결과로 표시하지 않는다. 이 보고서의 배치·경계·자산 재편 제안은 아직 제품에 적용되지 않았다. 비교 보드의 원본 캡션·credit는 공개 원문을 그대로 식별해 붙인다. S1의 원문 캡션은 “김경훈 오픈AI 코리아 총괄대표가 22일 데브데이 익스체인지에서 발표하고 있다. [사진: 오픈AI]”, S2는 “김경훈 오픈AI 코리아 대표 2026.10.22 ⓒ뉴스1 김정현 기자”다. T1의 사진은 원문이 명시한 저자 촬영이며 credit는 `Shimogauchi.R`다. 이 사진들의 제작자·촬영자 credit를 독립 시안의 제작 credit와 합치지 않는다.
