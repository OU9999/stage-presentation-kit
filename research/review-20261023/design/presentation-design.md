# 발표 디자인 제안 — 같은 배치에서 다른 읽기 만들기

담당: `/root/design_manager/presentation_designer`, 디자인 시안 취합 담당. Apple·Vercel 등 기업 발표의 명료한 주장·큰 결과물·여백이라는 관점으로 검토하는 역할이며 실제 기업 경력이나 해당 발표의 제작 참여를 뜻하지 않는다. 이번 산출물은 제품 반영 전 독립 제안이다.

## 핵심 결정

현재 #4의 12열×6행과 서로 다른 span은 원본과 가까운 뼈대다. 같은 크기의 갤러리나 임의 산개로 바꾸지 않고 **어떤 결과물을 보여 주는지, 무엇이 주역인지, 어디까지가 하나의 표면인지**를 먼저 고친다. [비교 시안](proposal.html)의 A/B는 경계의 효과를 분리하고 C는 한 이야기의 결과물로 다시 편집한 별도안이다.

## 시안의 읽기와 선택

- **A — 현재 처리.** 같은 자산·같은 배치의 비교 기준이다. 현재 제품과 글꼴·브라우저 렌더·주변 chrome까지 일치하는 clone은 아니다.
- **B — 경계 분리.** 현재 수치·사진·문구·UI와 fit을 고정한다. 바깥선의 부담을 줄여도 작은 UI와 무관한 소재 문제는 남는다. B에서 크롭·asset·문구를 바꾸지 않았다.
- **C — 권장 편집.** 원래 12span 골격을 유지하면서 콘텐츠·매체·위계를 바꾼 별도 디자인안이다. 오른쪽 세로 보고서가 주역이고 가운데 실행 UI가 보조 앵커다. 밝은 표지·작은 기록 조각·어두운 파형·도식이 각자 역할을 가진다. 모든 칸에 같은 copy+icon 형식을 반복하지 않는다.

C의 숫자·기록·UI는 모두 가상이다. 필기 인물 사진은 Pexels 스톡으로서 실제 연구 참여자나 프로젝트 사용자를 의미하지 않는다. C의 시각물은 자체 HTML/CSS/SVG와 기존 허용 스톡으로 만들었으며 OpenAI 원본 사진·앱 로고·캐릭터를 시안 자산으로 가져오지 않았다.

파트너의 실제 HTML 검토에서 나온 수정도 반영했다. 표지 그래픽의 최소 높이를 확보하고, 주제 도식은 여섯 중 세 주제의 발췌임을 표시했다. 하단의 추상적 공유 완료 문장은 발견 세 개에 대응하는 실행 목록 세 행으로 바꿨다. 작업 개념도를 설명하던 검토용 문구는 발표 슬라이드 안에서 제거했다. 이 변경은 C만 바꿨으며 A/B의 비교 변수는 유지했다.

## 제품 반영을 위한 편집 규칙

1. 혼합 요약은 앞에서 설명한 결과물의 회수 장으로 쓴다. 처음 보는 12가지 내용을 이 장 하나로 설명하려 하지 않는다.
2. 표지/작품/사진은 해당 비율에 맞춰 준비하고 초점을 지정한다. 전체 UI는 필요한 기능을 읽힐 크기로 발췌하거나 자체 축약한다. 문서 전체가 필요한 용도에서는 contain을 유지하고 읽어야 할 본문은 별도 장으로 넘긴다.
3. 어두운 구조선, 사진의 자연 edge, UI 자체 면, 도구 묶음의 관계를 구분한다. 모든 footprint를 공통 카드로 둘러싸는 규칙을 기본으로 삼지 않는다.
4. 큰 문자에 역할을 하나 준다. 핵심 수치·제품명·작품 타이포는 허용하고 설명 없이 다른 구호 두 개가 경쟁하는 구성은 줄인다. 한국어 줄바꿈은 실제 발표 크기에서 확인한다.
5. 숫자 색은 관찰/정리/행동의 의미를 연결한다. 경계선으로 복제하지 않는다. C의 작업 흐름은 수치 차트가 아닌 개념도다.

표시한 HEX·12% 선·반경·폰트 크기는 비교 시안을 위한 설계값이다. 현장 사진에서 추출한 공식 OpenAI 사양이 아니다. SF 기존24:00 문서/인용 장은 타임코드 대응이 **UNVERIFIED**여서 이 시안의 근거에서 제외했다. 정확한 전환·애니메이션·제작 소속도 이번 범위에서 확인하지 않았다.

## 직접 협의와 검증 상태

- 파트너 `/root/design_manager/devday_designer`와 A/B의 fit·크롭 고정, C의 단일 이야기, 보고서+UI 앵커, 모든 구획의 카드화 금지를 직접 합의했다.
- 정적 확인: A/B 공통 template 12개·C template 12개, HTML 로컬 링크 11개 누락 없음, 외부 미디어 없음, inline JavaScript 문법 통과. `presentation-design.md` 10개·파트너 문서 33개 로컬/원문 링크 중 로컬 대상 누락이 없었다. HTML에는 독립 data SVG favicon을 넣었다.
- 매니저의 [최종 C 화면](proposal-desktop-c.png)을 이 담당자도 직접 이미지로 확인했다. 표지 그래픽은 충분한 면적으로 보이고, 하단은 발견 세 개와 행동 세 개의 대응으로 정리됐다. 이 담당자는 브라우저를 조작하지 않았다. A/B/C 실제 조작·로컬 미디어·모바일 overflow·Console·Network의 최종 검증은 디자인 매니저 소유이며 해당 검증 기록과 구분한다.
- 제품 `app.js`·`styles.css`·`deck-model.js`·`slides.md` 및 생성된 예제는 수정하지 않았다. 이번 HTML 시안은 설치 없이 열리는 독립 검토 파일이다. 제품 테스트·PDF·전용 발표 모드 회귀가 끝난 제품 변경으로 보고하지 않는다.
