# 발표 전문가팀 1차 재구성안

- 담당: presentation_team
- 기준: 현행 40장과 대본 직접 확인; 사용자 제공 두 영상의 발언·화면 원문은 아직 미확인
- 성격: 현재 발표 진단에 근거한 독립 설계안. 영상 분석 결과 수신 뒤 수정 예정

## 지금 발표에서 집중이 흩어지는 지점

1. 청중이 결과를 보기 전에 정의·구조·작업 방식 설명 9장 선행
2. 독서·고객 요구·강의 메모의 세 가상 사례가 각각 입력부터 다시 시작
3. 같은 메시지인 개념·비교·종합·다음 질문을 장마다 반복
4. 초기 구현·논문 조건·고정 교정 데모가 큰 부록이 되어, 시작 행동보다 검증 경계가 더 눈에 띄는 분량
5. 한 번에 기억할 결과물이 실제 파일 한 개로 고정되지 않아, 발표 후 무엇을 만들어야 하는지 다시 해석 필요

## 새 중심 질문

**“이번 스터디에서 이해한 내용을 다음 질문에도 쓰려면?”**

청중과 같은 상황인 AI 스터디 자료를 입력으로 삼고, 한 묶음의 파일이 원자료→개념·비교→질문 답→갱신으로 바뀌는 장면을 끝까지 따라간다. 기술 이름을 여러 개 나열하기보다 무엇이 저장되고 언제 바뀌는지 같은 축으로 비교한다.

## 표현과 화면 원칙

- 한 장 한 문장, 큰 결과물 한 개
- 원자료·개념·비교·질문 문서의 경로를 고정해 장마다 새 구조 학습 방지
- 생성된 파일/화면은 구성 예로 표시; 실제 LLM 실행 결과로 소개 금지
- AI 스터디 맥락에서 설명하기 쉬운 파일 예제 우선. 고객 CSV는 짧은 변형 예 또는 학습자료로 이동 가능
- 출처는 한 장에 한두 개, 코드 SHA·논문 조건은 원문 안내로 이동
- 모든 장에서 면책 문구 반복 대신 시작의 구성 예 표시와 정확한 발언 범위로 처리
- 원영상의 장면 복제보다 실제 관찰한 설명 순서·확대·정보 밀도·비교 축 반영
- 18분 본편+2분 Q&A 시간 배분, 실제 낭독 측정과 구분
