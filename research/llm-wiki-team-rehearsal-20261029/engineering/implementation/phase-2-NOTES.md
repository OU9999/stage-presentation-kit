# Phase 2 즉시 기록 — 구현·근거 관점

읽은 범위: phase 1 기록 저장 뒤 phase-2 대본과 PNG 10→18 직접 실독. 외부 자료·미래 구간은 열지 않았다. 기록 시각은 아래 UTC로 붙인다. 실제 음성·대기 실험 없음.

- 10~12: 행동, 타인의 판단, 자기 설명, 미확인을 서로 다른 상태로 남기는 방식이 선명하다. 11장의 전후 파일 발췌가 데이터 갱신 단위를 보여 준다. 다만 10장 화면은 이미 3장의 추적 장치와 서하 자기 설명을 보여 주어 발언의 '1장에는' 시점보다 앞선다. 11장의 변화가 완전히 새로운 발견으로 오지는 않는다. 화면 자체의 예고이며 미래파일 선독은 아니다.
- 13: 직접 생각한 답은 '형식 CSV는 같아도 목적/주기/전달 방식이 달라 같은 구현 요구로 합치면 안 된다'. 5초를 실제 재지 않았고 다른 참여자의 반응도 없다.
- 14~15: 원래 요구를 보존하고 팀의 현재 상태를 별도로 고친다는 구분이 실무에 잘 붙는다. '범위 검토/보류/미확정'은 출시 약속으로 확대하지 않는다. 상태의 기준 시각과 회의별 출처를 실제 파일에서 어떻게 유지하는지 궁금하다.
- 16~18: 공유 개념→비교 조건의 확장→질문에서 얻은 종합 저장이라는 반복을 재확인한다. 16장 화면에는 새 8주차/Gini가 이미 있고 17장의 새 비교 행에서 다시 설명된다. 이 예고는 설명 구조를 이해시키지만 실제 변화 전후의 놀라움은 줄인다.
- 세 사례는 모두 가상 구성/실행 결과 아님을 발언 또는 화면에 명시한다. '예제로 갱신 구조를 이해했다'와 '모델이 이 품질로 갱신함을 관찰했다'를 분리해야 한다.
