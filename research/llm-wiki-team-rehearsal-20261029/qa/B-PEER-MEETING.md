# QA A↔B 직접 교차회의 — B 기록

## 개시와 읽은 범위

Manager가 A/B 모든 구간과 개별 최종 독립 파일의 실물을 확인한 뒤 교차회의를 개시했다. B는 이때 처음 `A-FINAL-INDEPENDENT.md`를 읽었고, A의 24장 실제 질문과 한계를 정확히 인용하기 위해 `A-phase-3.md`를 추가로 읽었다. A/B 독립 파일은 변경하지 않았다. 학습서·링크 목적지·제품 원본은 계속 열지 않았다.

## 실제 직접 교환

1. B→A `send_message`: 공통 근거를 10·16장 공개 순서, 39장 가독성, 25장 이후 첫 실행 연결로 제시했다. 10장은 1장 상태만/3장은11장, 16장은2·7주차만/8주차는17장에 공개하는 안과, 어렵다면 발화를 전체 전후 소개로 고치는 대안을 보냈다. 39장 네 카드 폭/본문 크기와 제목 온전 표시, 26장 두 확인 질문을 후순위로 제안했다. A의 강의 활용·복구 관심과 B의 회의/피드백·중복/Lint 관심이 적용 관점 차이라고 물었다.
2. A→B 실제 메시지: 독립 파일을 읽고 같은 10·16·39장 이슈를 제시했다. 39장 마지막 ‘다’가 PNG에서 보이지 않지만 원인은 미확인임을 강조했다. B의 26장 두 질문을 받아 화면 하단에 두는 안에 동의했고, 10·16장은 화면을 이전 상태로 제한하는 쪽을 선호한다고 밝혔다. 자신의 초점은 첫 실행과 실제 읽음 확인이었다고 구별했다.
3. B→A 실제 회신: 화면을 이전 상태로 제한하는 안을 우선안으로 동의하고 발화 수정은 대안으로 남겼다. A의 복구·실제 읽은 구간 확인 질문을 ENG 인계에 포함하기로 했다. 26장 제안은 후순위, 첫 실행은 후속 목적지 미검증 상태로 기록한다고 답했다. 서로의 활용 선호를 충돌하는 수정 요구로 만들지 않기로 했다.
4. A→B 실제 확정 답: 10장은1장만/3장은11장, 16장은2·7주차만/8주차는17장 공개를 공동 우선안으로 확인했다. 39장 PNG 관찰/원인 미확인과 26장 두 질문에 동의했다. A의 강의 개념 비교·복구/읽음 확인과 B의 요구·상태·판단·중복/Lint 관심을 남는 선호 차이로 유지해 달라고 했다. 원리는 이해했고 시도 의향은 생겼지만 첫 실행을 혼자 재현할 자신을 확인한 것은 아니며, 학습서 목적지는 미검증이고 24장도 대본 선노출·타이머 없음이라는 한계를 꼭 남겨 달라고 요청했다.

이 기록은 실제 양방향 메시지 내용을 정리한 것이며 사람 회의·음성 대화 기록이 아니다.

## 확정 합의

- 10·16장은 화면과 발화의 시점을 맞춘다. 우선은 후속 입력을 각각11·17장으로 늦추고, 전체 소개 발화로 맞추는 안은 대안이다.
- 39장은 네 종류의 근거를 동등하게 읽을 수 있도록 카드 폭/본문 크기와 제목을 확인한다. 현재 확인은 PNG 외형이며 CSS·레이아웃·렌더링 원인은 미확인이다.
- 26장 확인 문구는 후순위 개선: “필요한 근거를 다시 찾았나? / 잘못된 정리를 고칠 부담을 감당하나?”가 화면에서도 읽히게 한다.
- 첫 실행은 발표에서 일부 미해결이다. 학습서·실습 목적지를 보지 않아 그곳에 안내가 없다고 주장하지 않는다. 본문 증량보다 연결된 실습 첫 단계의 확인을 선호한다.
- 고객 사례, 역할 구분, 실제 재읽기, 자기 질문 한 줄, 작은 검증, 기본/선택 심화 구분을 유지한다.

## 실제 남은 차이

A는 강의 개념의 조건 비교와 첫 환경·복구·실제 읽은 구간 확인에 더 관심이 있다. B는 회의/피드백의 요구·상태·판단 보존과 중복·Lint 후보 처리에 더 관심이 있다. 수정 방향의 충돌은 확인되지 않았다. 개인 역할의 활용 선호 차이이며 실제 다수 청중의 선호로 일반화하지 않는다.

## 취합 실물 교차검토

`QA-SYNTHESIS.md` 작성 후 A에게 실물 검토를 직접 요청했다. A는 실제 파일을 읽고 자기 관점·24장 정확 질문·한계·우선순위·차단 판단·ENG 인계가 왜곡 없이 반영됐으며 수정 요청이 없다고 회신했다. Manager의 간결 취합 지침에 따라 B는 중복 강점표를 네 유지점으로 줄이고 변경안도 네 갈래로 정리했다. A는 간결화 완료본도 다시 직접 열어 같은 항목이 정확하며 추가 수정 요청이 없다고 최종 회신했다. Manager 지침대로 ENG 인계는 후속 검증 질문이며 제품 수정 위임이 아니라는 문장도 명시했다. B의 회의/취합 파일 편집을 종료한다.
