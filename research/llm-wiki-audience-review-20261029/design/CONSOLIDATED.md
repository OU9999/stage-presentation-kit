# 40장 발표의 디자인·모의 청중 종합 권고

**정돈된 교육 자료라는 강점은 있으나, 가벼운 약20분 Zoom 발표로 충분히 선명하고 흥미롭다는 완료 판정은 보류한다.** 다음 개선은 사진·차트 수보다 실제 바뀐 문장, 다음 질문에 쓴 기록, 청중이 적을 한 줄을 먼저 보이게 하는 편집이다. 현재 제품은 수정하지 않았다.

대상: main `a5b558c`, 원고 `7dbd19ff…077c28`, 40장. [B 초기 평가](visual-review.md)는 02:58:42 UTC에 동결했고, [독립 senior 평가](senior-review.md)와 [모의 청중 종합](../audience/SYNTHESIS.md)은 그 뒤 읽었다. 두 디자이너가 개별 40장과 발언 40구간·공식 저장 프레임 네 개를 직접 확인하고 일대일로 근거를 대조했다. B의 제작 사전 지식/로그 노출과 모의 청중의 초기 선노출은 각 원문에 남겼다. 완전 블라인드·실제 관객 연구·실제 회사 경력을 주장하지 않는다.

## 유지할 강점

- **1장 도입, 8장 구조, 22장 재사용, 24장 현행/보류, 26장 결정 대체**에는 사진·공간·연결이 실제 설명 역할을 한다. 특히 22/24~27의 기록 재사용은 모의 청중 두 역할도 유익으로 남겼다.
- **17장의 실제 교정 내용은 유지한다.** 모의 청중은 한 문장을 근거 대조에서 변경까지 따라갈 수 있다는 내용을 강점으로 봤고, 디자인은 그 바뀐 범위가 작은 본문에 묻힌다고 봤다. 두 판단은 양립한다. 문장 전체를 지우지 않고 핵심 범위를 먼저 크게 읽게 한다.
- **35장 자기 질문 쓰기와 40장 종료 질문**은 자기 자료로 넘어갈 통로다. 정확한 실행 범위·불확실성·검토 비용의 구분도 보존한다. 다만 같은 한계를 여러 장에서 길게 반복하지 않는다.

## 모의 청중과의 동의·차이

모의 청중은 역할 기반 워크스루이며 실제 사람의 반응이 아니다. 두 역할 모두 22/24~27의 재사용을 설명했지만, **처음 듣는 역할은 자기 도구에서 시작하는 순서가 여전히 막막했고, 실무 적용 역할은 동료와 검토할 질문을 정하는 출발은 가능하다고 봤다.** 이를 평균 만족도나 한 개 합격 판정으로 합치지 않는다.

디자인의 19장 ID 부담, 12/23의 쉬운 정답 단서, 31장의 비중 우선은 청중 기록과 같은 방향이다. 청중의 ‘LLM 역할 구체화가 늦다’는 지적을 읽은 뒤 senior는 8~10의 작업 장면을 초기보다 높은 우선순위로 올렸다. B는 초기부터 같은 문제를 별도로 기록했다. 독립 판단과 사후 변경을 구분한다.

root도 사후 23장 PNG를 대조해 ‘주세요. 이 / 예제의…’라는 의미 단위 줄갈림과 오른쪽 안내 치우침을 재확인했다. 이는 B/senior의 초기 선택지 위계 지적에 대한 **사후 대조**이며 초기 독립 증거에 소급해 섞지 않는다.

## 시간과 후속 확인

현행 30분+별도Q&A2분은 리허설 전 계획이다. 원래 약20분에 맞춘다면 핵심인 실제 교정·재사용·보류·결정 대체·자기 질문은 남기고, 절 번호/LoRA 부연/JSON 필드/목차 이력/확장 운영법 일부를 심화 경로로 넘기는 편을 검토한다. 30분 강의를 선택한다면 도입과 같은 오류 설명의 반복을 줄여 실제 한 파일을 더 빨리 보여 준다.

후속 사람 리허설에서는 실제 Zoom 공유+채팅 크기에서 ①10장 뒤 LLM/사람/오늘 실행 구별, ②17~26 뒤 바뀐 범위와 재사용 이유, ③35장에서 실제 적힌 질문과 막힌 이유를 확인한다. 수행 시간·발표자의 속도·실제 작성물·질문을 기록하기 전에는 참여 효과나 학습 성공을 주장하지 않는다. 네 공식 정지 프레임과 같은 검은 배경·큰 글자·색을 갖췄다는 이유로 같은 발표 완성도라고 평가하지 않는다.

## 직접 청중 인수와 종료

독립 판정과 디자인 교차 검토 뒤 B가 `/root/audience_review_manager`에게 세 질문을 직접 보내 대조했다. 회신은 다음을 확인했다. A/B의 공통 질문은 **오늘 실행 경계를 전혀 이해하지 못했다는 뜻이 아니라**, 실제 운영에서 LLM이 하는 일을 더 일찍 구체화해 달라는 것이었다. 도구의 파일 지정·읽기·수정안 확인·저장 첫 동작에 대한 불안은 A에게 더 분명했고 B는 기존 Markdown/동료 검토에서 출발 가능하다고 봤다.

17장 내용 강점과 시각 위계 보완은 양립하며 실제 전체 문장을 남기는 안에 동의했다. 35장의 질문 한 줄 우선·제목은 기억나는 만큼·근거는 다음 모임이라는 안도 과제 부담을 낮추는 합리적 제안으로 인수했다. **A의 도구 첫 동작이나 B의 pending 운영 질문까지 해결했다거나, 20초가 충분하고 실제 작성에 성공했다고 확장하지 않는다.** 청중 manager도 세 시안 PNG와 31장의 서로 다른 검사 단위·한계를 직접 확인했다.

B 소유 초기 `visual-review.md` 동결 본문은 유지했고, 이 취합 문서의 편집을 종료한다. 실제 제품은 동결된 그대로이며 후속 구현·실제 사람/Zoom 리허설은 완료 범위에 포함하지 않는다.
