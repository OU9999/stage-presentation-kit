## 새 구성의 실제 동작

- `seoul`: computed grid12열×6행, 타일12개 모두 캔버스 내부. `recap`:6열×3행,12개. 프리셋에는 빈칸·겹침이 없고 모바일 입력 순서를 보존한다.
- `icon-wall`:8열×5행,22개 외곽 타일과 중앙 메시지의 교집합0. SVG는 viewBox24·stroke1.8로 고정하고 사용자 마크업을 삽입하지 않는다.
- `metric-pair`:2열, 동등한 숫자 크기와 기준선, 파랑·주황 의미색. 숫자는 양식용 가상 값이다.
- 새 bento 항목 라벨·아이콘월 제목·두 수치 라벨을 **실제 편집 기능으로 변경 → 새로고침 복원 → content.js 다운로드**했다. 내려받은 파일을 실행해 3개 값이 동일함을 확인했다. 전용 QA 폴더에서 실행했으며 배포 예제 원문은 바꾸지 않았다. [편집·내보내기 기록](evidence/implementation/interactions-stage1.json).
- 실제 발표자 버튼으로 연 창에서 bento→아이콘월→두 수치의 현재/다음 미리보기·노트 동기화, 발표자 창→청중 화면 역방향 이동을 확인했다. 전체보기7개와 SVG27개도 렌더된다.
- 실패 입력은 bento11개·아이콘월23개·두 수치1개를 넣었다. 해당3장만 오류 카드로 표시되고 앞 bento와 뒤 표지는 정상이다. 오류 경로와 원본11/23/1개를 화면·실제 다운로드 모두에서 확인했다. [격자·발표자·오류 기록](evidence/implementation/presenter-geometry-errors.json).

## 관찰과 구현의 경계

SF 영상은 지정 구간의 재생·프레임 확인이며 전편 시청이 아니다. 서울·도쿄·벵갈루루는 현장 정지 사진으로 확인했다. 벵갈루루 수치의 슬라이드 제작 소속은 미확인이어서 OpenAI 공식 디자인 규칙으로 채택하지 않았다. 도쿄의 관계도·중립 아이콘 카드 레이아웃은 이번에 별도로 구현하지 않았다.

원본 6명의 촬영·조명·아트 디렉션을 재현한 것은 아니다. 서로 다른 스톡 장면에서 크롭·프레임·정보 위계를 개선했다. 픽셀 치수·정확한 HEX는 STAGE의 독자 구현값이며 현장 투사 사진에서 공식 CSS를 추출한 값이 아니다. 물리 프로젝터·리모컨·다른 운영체제와 브라우저는 미검증이다.
