# 최종 예제 디자인 검수

2026-10-24 · `/root/design_manager`

**최종 정적 디자인 검수 통과.** 발견한 PNG 출력 누락 두 건은 총괄이 교정했고 재검수에서 해소됐다. 제품·SVG 디자인의 추가 수정 의견은 없다.

## 정적 대조

매니저가 [개별 01–12장 PNG](../evidence/slides/01.png), [대표 미리보기](../../../examples/previews/visual-story.png), [전체 모음](../../../examples/previews/visual-story-overview.png)을 직접 열고 native 제목·한 줄 메시지·그래프의 조합을 확인했다. 최종 8개 SVG를 XML로 읽고 현재 제품 `data.json`에서 생성한 값과 8/8 바이트 일치도 확인했다.

| 범위 | 관찰 |
| --- | --- |
| 표지·KPI | 큰 문장과 의미색 한 단위, 35%·55% 숫자와 중립 단위, +20%p 메시지·두 기간/분모가 구분됨. |
| 퍼널·추세 | 같은 가입 분모·0 시작 정렬 막대, 누락 없는 12주·0–100% 축, W13 집계 주석이 보임. |
| 구성비·단계율 | 선정 응답자 48명 분모·긴 범례, 단계율 81.3%·84.6%, 마지막 구간 차이 +14.6%p 표시가 정상. |
| 여정·우선순위 | 네 단계와 제안의 대응, 번호+우측 목록의 매트릭스가 분리되어 라벨 충돌이 보이지 않음. |
| 일정·투입 | W1–W12 실행과 W13 집계가 구분되고 히트맵 9셀·행/열 합·총 18인·주·범례가 보임. |
| 다음 검증 | 세 제안과 점검 방법을 native 세 열로 읽을 수 있으며 설명·제목이 서로 겹치지 않음. |
| 닫는 장·전체 모음 | 교정된 12장의 두 줄 문장·설명·`data.html` 링크가 완전히 보이고, 전체 모음의 12장 모두 세 행에 표시됨. |

개별 1–11장과 대표 4장 미리보기에는 제목·자료·주석의 잘림이나 추가 디자인 수정 의견이 없었다. 최초 전체 모음은 첫 행만 완성되고 아래 자료가 비어 있었으며 최초 12장 PNG는 검정으로 비어 있었다. 이 두 캡처 문제를 총괄에게 직접 통지해 내용 렌더·효과 종료 후 재생성을 요청했다. 제품 코드 결함으로 단정하지 않았으며 닫는 원고의 제목·설명·`data.html` 링크 데이터는 정상이었다.

총괄 교정 후 새 [12장 PNG](../evidence/slides/12.png)·[전체 모음](../../../examples/previews/visual-story-overview.png)·[대표 미리보기](../../../examples/previews/visual-story.png)를 다시 직접 열었다. 닫는 문장과 링크가 화면 안에 완전히 표시됐고 전체 12장도 세 행에서 누락 없이 보였다. 두 출력 문제의 해소와 통과 결과를 총괄에게 직접 통지했다.

## 엔지니어링의 재사용 경계 보완

최종 `scripts/visual-story/theme.cjs`, `charts.cjs`, `diagrams.cjs`를 읽었다. 작은/0 구성비 구간의 내부 비율은 공간이 부족할 때 생략하되 범례의 인원·비율은 유지한다. 투입 고유값이 많을 때 실제 최소·중간·최대의 대표 범례를 최대 3개로 제한해 경계 이탈을 피한다. 가장 큰 단계 변화는 절대 변화폭으로 고르며 원래 부호를 보존한다. 단일 주 일정은 짧은 W 라벨을 사용한다. 이 보완은 확정 팔레트·원본 숫자·최종 데이터의 시각 구성을 유지한다.

SVG는 여전히 1280×640·title/desc·native 제목과 별도의 plot 구조이며 외부 런타임·사진을 추가하지 않는다. 모바일의 미세 축 가독성은 이 PNG 정적 검수의 통과 범위가 아니며 같은 데이터의 실제 HTML 표·요약이 대안이다.

브라우저·제품 코드·WORK_LOG·PNG·PDF를 수정하지 않았고 실무자를 재개하거나 새로 생성하지 않았다. 이 문서만 정리한 뒤 편집 종료한다. 실제 발표 조작·모바일 표·오프라인·PDF 검수는 총괄과 엔지니어링의 근거를 따른다.
