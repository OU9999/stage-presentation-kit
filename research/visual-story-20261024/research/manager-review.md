# 데이터 이야기 리서치 검수

2026-10-24 · 리서치 매니저 `/root/research_manager`

가상 제품의 첫 경험 개선을 설명하는 12장 계약을 검토했다. 2–10장의 KPI·퍼널·시계열·구성비·단계 비교 막대·여정 흐름·우선순위 매트릭스·일정·투입 히트맵은 서로 다른 아홉 표현이며, 하나의 관찰·판단·다음 행동 이야기로 연결한다. 실제 성과나 인과 효과를 입증하는 자료가 아니다.

## 숫자와 연결 검수

- [데이터 계약](data-contract.md)과 [단일 연구 입력](dataset.json)을 읽고 별도 Python 계산으로 **18개 검사 그룹**을 통과했다. 실제 결과는 [manager-checks.json](manager-checks.json)에 보관했다. 데이터 실무자의 19개 검사 그룹과 별도로 수행한 검수다.
- 기준·적용·후반은 각각 신규 1,200명이며 활성 420·546·660명이다. 전체는 신규 3,600명·활성 1,626명이다. 35%→55%는 +20%p이며 상대 변화 +57.1%와 구분한다.
- 퍼널은 가입 ≥ 시작 ≥ 초안 ≥ 공유의 중첩을 만족한다. 인접 단계 전환율은 같은 퍼널 정수에서 다시 계산하며 마지막 구간 차이 +14.6%p가 가장 크다. `81.25%→81.3%`는 표시 시 사사오입으로 통일한다.
- 인터뷰는 전체 사용자 비율이 아닌 선정된 가상 응답자 48명의 분류다. 18·12·10·8명은 합 48명이며 표시 비중 37.5·25.0·20.8·16.7%의 합은 100.0%다.
- 기획 점수와 여정·후속 계획의 참조 ID, 주차 범위, 3×3 투입 행렬을 확인했다. 투입 행 합은 각각 6인·주, 열 합은 5·7·6인·주, 총합은 18인·주다. 경과 12주와 인·주는 다른 단위다.
- 초기 서사의 ‘저장’과 데이터 정의 ‘첫 프로젝트 공유’가 달랐던 지점을 실무자에게 직접 수정 요청했다. 최종 관찰은 가입 후 7일 안의 첫 프로젝트 공유이며 W12 코호트까지 같은 창을 마친 W13 종료에 확정한다.
- 표 앵커는 `periods`, `weekly`, `funnel`, `interviews`, `step-rates`, `journey`, `priorities`, `roadmap`, `effort`, `next-validation`의 한 세트로 확정해 양 실무자에게 직접 전달했다.

## 구현·디자인으로 넘기는 범위

실제 편집 원본은 후속 제품의 `examples/visual-story/data.json` 하나로 둔다. 이 연구의 JSON은 확정 입력 스냅샷이다. 같은 입력에서 SVG·실제 HTML 표와 요약·숫자가 들어간 발표 원고를 재생성해 수치를 손수 중복 관리하지 않는다. 기존 19개 양식과 Markdown·공통 색·5종 모션으로 구성할 수 있으며, 현재 요구에 새 범용 차트 런타임을 추가할 구체적인 필요는 없다.

SVG는 `image`의 `contain`으로 표현하고 큰 패턴·핵심 값에 집중한다. 작은 화면의 세부 숫자는 `data.html`의 실제 표와 요약으로 읽을 수 있어야 한다. 닫는 장의 `url: data.html`은 클릭 가능한 진입점이며 각 장의 노트와 가이드에는 해당 앵커를 안내한다. raw JSON만 대안으로 제공하지 않는다.

매니저는 W3C의 [복잡한 이미지 지침](https://www.w3.org/WAI/tutorials/images/complex/) 원문을 확인했다. 짧은 대체 텍스트와 값·관계·경향을 담은 상세 설명을 함께 제공하는 원칙을 적용한다. 이 지침 확인을 전체 접근성 준수 검증으로 확대하지 않는다.

제품 코드·WORK_LOG·Git은 이번 리서치에서 수정하지 않았다. 시각 사양·실제 생성 결과·모바일·보조기기·PDF 검증은 디자인·엔지니어링·총괄의 후속 범위다.
