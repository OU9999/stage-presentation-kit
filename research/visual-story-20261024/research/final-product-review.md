## 독립 계산과 내용 대조

- 기준 W1–W4는 420/1,200 = 35%, 적용 W5–W8은 546/1,200 = 45.5%, 후반 W9–W12는 660/1,200 = 55%다. +20%p는 두 비율의 차이이며 상대 변화 +57.1%와 구분돼 있다.
- 12주 합계는 신규 3,600명·활성 1,626명이다. W1 30%·W12 58%는 주별 값으로 표시한다. 가입 후 7일 안의 첫 프로젝트 공유가 활성 기준이며 W12 코호트까지 관찰한 W13 종료가 집계 시점이다.
- 퍼널의 1,200→840→600→420명과 1,200→960→780→660명은 기간 집계와 일치한다. 직전 단계 전환율은 별도 분모를 사용하며, 81.25%는 81.3%로 표시한다. 마지막 연결의 관찰 차이 +14.6%p도 원본 정수에서 계산한 값과 같다.
- 인터뷰 18·12·10·8명은 합 48명이다. 37.5·25·20.8·16.7%는 이 응답자 안의 분포이며 전체 신규 사용자 발생률로 표현하지 않는다.
- 우선순위 네 과제는 1–5점 기획 판단으로 표시한다. 흐름도는 기능·마찰·경험 단계의 대응이며 이동 인원이나 인과 관계를 뜻하지 않는다. 일정과 투입도 가상 계획이다.
- 투입 행렬의 행 합은 6·6·6인·주, 기간 합은 5·7·6인·주, 전체는 18인·주다. 경과 12주와 다른 단위라는 설명이 SVG와 표에 남아 있다.

Python `HTMLParser`로 실제 표 10개를 읽고 기간·주별·인터뷰·우선순위·일정·투입 행을 JSON 원본의 별도 계산과 대조했다. 표 앵커 열 개가 존재한다. Markdown의 장별 JSON 열두 개와 `content.js`의 ID·노트·캡션도 서로 일치했다. SVG XML 여덟 개의 수치·단위·기간·계획 표기를 읽고 개별 PNG 1–11장을 직접 열었다. 값과 도형의 의미에 추가 이견은 없다.

## 검수 중 발견한 연결 문제

발표자 노트의 그림 출처가 자료 종류와 관계없이 기준/후반 기간을 반복하는 문제를 엔지니어링 매니저에게 직접 전달했다. 인터뷰는 W2–W4, 추세는 W1–W12이며 기획 도식은 관찰 성과와 구분해야 한다. 엔지니어링이 공통 출처의 고정 비교 기간을 제거했고, 매니저는 최종 `slides.md`·`content.js`에서 변경을 직접 확인했다. 각 자료의 실제 기간과 종류는 해당 SVG·표에 남아 있다. HTML의 활성 정의 문구도 함께 교정됐다. 엔지니어링의 회귀 RED→GREEN 및 전체 181개 통과 보고는 매니저의 별도 테스트 실행 결과로 간주하지 않는다.

개별 12장 PNG와 전체 모음의 일부가 검게 캡처된 것도 총괄·디자인 매니저에게 전달했다. 원고의 닫는 제목과 데이터 링크 자체는 존재하므로 출력 문제와 제품 데이터 문제를 구분했다. 총괄이 효과 종료와 최종 투명도를 확인해 다시 출력한 뒤, 매니저가 [교정된 닫는 장](../evidence/slides/12.png)과 [12장 전체 모음](../../../examples/previews/visual-story-overview.png)을 다시 직접 열었다. 닫는 문장·설명·데이터 링크와 세 행 열두 장의 내용이 모두 표시된다. [최종 출력 근거](../evidence/artifact-render.json)도 12장·SVG 여덟 개 로딩·PDF 정적 12장을 기록한다. PDF의 실제 페이지를 여기서 다시 렌더한 것은 아니다.
