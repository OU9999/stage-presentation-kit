# 가상 데이터 계약

2026-10-24 · 데이터 분석 담당 `/root/research_manager/data_analyst`

[dataset.json](dataset.json)은 새 `examples/visual-story/data.json`의 입력 계약이다. 이 단계에서는 연구 원본만 작성한다. 후속 생성기는 같은 원본으로 발표의 SVG·수치와 **실제 HTML 표·요약을 포함하는 `data.html`**을 함께 만들어야 한다. JSON 파일만 제공하는 방식은 접근성 대안으로 충분하지 않다.

## 단위와 집계

- 모든 수치는 발표 양식을 위한 가상 값이다. 실제 회사·실제 성과·통계적 유의성·인과 효과를 주장하지 않는다. `fictional`, `disclosure`, `studyDesign`을 표지·데이터 안내·표의 출처에 연결한다.
- W1–W12는 가상 프로젝트 주차다. 매주 신규 가입 고유 사용자 300명을 한 코호트로 삼는다. 여기서 신규는 방문·유입이 아니라 **신규 가입**을 뜻한다. 가입 후 7일 이내 첫 프로젝트를 공유하면 활성화로 집계한다. W12 가입자도 7일 관찰을 마친 **W13 종료**가 보고 확정 시점이다.
- 기준은 W1–W4, 변경 적용은 W5–W8, 후반 관찰은 W9–W12다. 기간별 신규·활성 인원은 `weeklyCohorts`를 먼저 합산한다. 주별 활성화율을 반올림한 뒤 평균하지 않는다.
- 퍼널의 가입·최종 공유 인원은 위 기간 집계값을 참조한다. JSON에 같은 끝값을 다시 적지 않는다. 중간 단계만 `funnel.intermediateCounts`에서 읽는다. 단계는 고유 사용자 중첩집합이며 `가입 ≥ 시작 ≥ 초안 ≥ 공유`를 만족한다.
- 인터뷰는 W2–W4 미활성 사용자 중 선정한 가상 48명이다. 대표 마찰 원인 하나만 분류했으므로 네 원인 합계가 48명이다. 전체 사용자 비율이나 이탈 인과 원인으로 일반화하지 않는다.
- 영향·노력 점수는 가상 기획 판단의 1–5점 순서척도다. 측정 결과·성공 확률·객관적 ROI로 해석하지 않는다. 네 우선순위 항목은 측정값이 아니다.
- 여정 관계도는 기능 제안이 어디를 돕는지 보여준다. 화살표는 실제 이동 인원·상관·검증된 인과 효과를 뜻하지 않는다. 흐름 인원이 필요하면 별도의 퍼널 정수를 사용한다.
- 일정은 시작·끝 주를 모두 포함한다. 동시 과업은 허용한다. 투입량의 인·주는 한 사람의 전일 1주 계획량이며 경과 12주와 합산하지 않는다.
- 후속 검증 계획은 W14–W15의 가상 조사·점검 계획이다. 결과 수치가 아직 없으며 사용성 점검을 활성화율의 인과 효과로 제시하지 않는다.

## 계산 규칙과 확정 값

비율은 원본 정수로 계산하고 표시할 때만 소수 첫째 자리로 사사오입한다. 예를 들어 81.25%는 81.3%다. 정수 비율은 `.0`을 생략할 수 있다. 천 단위 구분은 `1,200명`처럼 표시한다. 음수 변화는 부호를 유지한다.

| 항목 | 계산 | 확정 값 |
| --- | --- | --- |
| 전체 신규·활성 | 12주 각 인원 합계 | 3,600명 · 1,626명 |
| 기준 활성화율 | W1–W4 활성 합 / 신규 합 | 420 / 1,200 = 35% |
| 적용기 활성화율 | W5–W8 활성 합 / 신규 합 | 546 / 1,200 = 45.5% |
| 후반 활성화율 | W9–W12 활성 합 / 신규 합 | 660 / 1,200 = 55% |
| 절대 비율 차이 | 55 − 35 | **+20%p** |
| 상대 비율 변화 | (55 − 35) / 35 × 100 | **+57.1%**; +20%와 혼용 금지 |
| 기간별 활성 인원 차이 | 660 − 420 | +240명; 서로 다른 기간 코호트의 관찰 차이 |
| 첫·마지막 주 비율 | 90/300 · 174/300 | W1 30% · W12 58%; 35%·55%는 각각 4주 집계임 |
| 기준 퍼널 | 신규·시작·초안·공유 / 신규 | 1,200·840·600·420명 / 100·70·50·35% |
| 후반 퍼널 | 신규·시작·초안·공유 / 신규 | 1,200·960·780·660명 / 100·80·65·55% |
| 인터뷰 원인 | 18·12·10·8 / 48 | 37.5·25.0·20.8·16.7%; 합 100.0% |
| 기준 단계별 전환율 | 시작/가입 · 초안/시작 · 공유/초안 | 70.0% · 71.4% · 70.0% |
| 후반 단계별 전환율 | 시작/가입 · 초안/시작 · 공유/초안 | 80.0% · 81.3% · 84.6% |
| 계획 투입 행 합계 | 조사(3+2+1), 설계(1+3+2), 개발·품질(1+2+3) | 각 6인·주, 총 18인·주 |
| 계획 투입 기간 합계 | 기준(3+1+1), 적용(2+3+2), 후반(1+2+3) | 5 · 7 · 6인·주, 총 18인·주 |

구성비 도형의 면적·길이는 반올림 전 값을 사용한다. 반올림 비율 합이 100%가 되지 않는 다른 데이터로 바꿀 때는 각 값을 억지 조정하지 말고 주석을 남긴다. 현재 인터뷰 구성비는 100.0%로 표시 가능하다. 역할 투입은 세 역할 각각 33.3%로 표시하면 합이 99.9%이므로 주석이 필요하며, heatmap에는 비율 대신 인·주 원값을 권장한다.

## `data.html`의 실제 표

HTML에는 해당 표를 설명하는 제목·짧은 메시지·가상/기간/단위/분모 주석을 함께 두고 `<table>`, `<caption>`, `<thead>`, `<th scope>`를 사용한다. SVG 대체 텍스트에는 결론과 필요한 숫자를 요약하고, 정확한 값은 아래 표에 연결한다. 기존 런타임의 `source`는 텍스트 표시이므로 링크로 오해하지 않는다. 노트에 주소를 남기고 작성 가이드의 실제 링크 및 닫는 장의 `url: data.html`로 표를 열 수 있게 한다.

| 권장 anchor | 실제 표 컬럼 | 데이터 원천 |
| --- | --- | --- |
| `weekly` | 주차 / 신규 가입(명) / 7일 내 공유(명) / 활성화율(%) | `weeklyCohorts` |
| `periods` | 기간 / 주차 범위 / 신규(명) / 활성(명) / 활성화율(%) | `periods` + 주별 집계 |
| `funnel` | 단계 / 기준(명) / 기준 전체 전환율(%) / 후반(명) / 후반 전체 전환율(%) | 퍼널 중간값 + 기간 끝값 |
| `step-rates` | 구간 / 기준 통과자(명) / 기준 직전 단계(명) / 기준 전환율(%) / 후반 통과자(명) / 후반 직전 단계(명) / 후반 전환율(%) | 같은 퍼널의 인접 단계끼리 나눔 |
| `interviews` | 대표 원인 / 응답자(명) / 48명 중 비율(%) | `interviews` |
| `priorities` | 개선안 / 예상 영향(1–5) / 노력(1–5) / 기획 우선순위 | `initiatives` |
| `journey` | 기능 제안 / 대응 단계 / 참고 인터뷰 분류 | `journeyMap`의 ID를 원본 라벨로 연결 |
| `roadmap` | 과업 / 시작 주 / 종료 주 / 경과 주수 | `roadmap`; `종료−시작+1` |
| `effort` | 역할 / 기준 계획(인·주) / 적용 계획(인·주) / 후반 계획(인·주) / 행 합계(인·주) | `effortAllocation`; 열·전체 합계도 표시 |
| `next-validation` | 개선안 / 다음 질문 / 점검 방법 / 살필 항목 / 판단·다음 행동 | `nextValidation`; 결과가 아닌 계획으로 라벨 |

모바일에서는 SVG를 단순 축소해 읽게 하지 말고 같은 장의 한 줄 요약과 표 링크를 함께 제공한다. 표는 작은 화면에서 셀을 누락하지 않는 스크롤 영역 또는 단순한 행 카드로 읽을 수 있어야 한다. 원본과 계산·대체 표를 같은 생성 명령으로 갱신해 서로 다른 숫자가 남지 않게 한다.

## 숫자 검증

최종 JSON을 Python으로 읽고 다음 **19개 검사 그룹이 모두 통과**했다. 가상 표시·7일 관찰창, 주차 연속·고유성, 정수 영역·주별 양의 분모와 활성≤신규, 세 기간의 중복 없는 완전 분할, 기간별 합계와 전체 합계, 핵심 비율·상대 변화, 퍼널 순서·중첩, 인접 단계 비율, 인터뷰 인원 합과 표시 비율 합, 기획 점수 범위, 여정 ID 참조, 일정 경계, 투입 행렬 차원·기간 참조·양수, 행·열·전체 합계, 후속 계획의 과제 참조를 검사했다.

검사 결과는 기준 420/1,200·적용 546/1,200·후반 660/1,200, 전체 1,626/3,600, 인터뷰 48명·100.0%, 계획 3×3행렬·18인·주다. 단계별 전환율은 `Decimal`의 사사오입으로 기준 70.0/71.4/70.0%, 후반 80.0/81.3/84.6%를 확인했다. 후속 생성기에서도 이 계약을 자동 검증하고 입력이 바뀌면 파생 SVG·표·원고를 함께 다시 생성해야 한다.
