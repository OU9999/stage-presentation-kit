# LLM Wiki 도식의 시각 언어 교정

2026-10-29. [10장 전후 비교](./index.html) · [발표](../../presentations/llm-wiki/#4).

사용자가 지적한 문제는 같은 색 테두리 박스에 설명을 넣고 연결선을 늘린 구도였다. 앞선 검수에서 화면 잘림과 기술적 정합성에 비해 도식의 조형과 읽는 순서를 충분히 검토하지 못했다. 해당 판단을 유지 근거로 삼지 않고, 사용 중인 도식9종·발표10장을 다시 그렸다.

## 달라진 구도

| 장 | 전달할 관계 | 바꾼 시각 표현 |
| --- | --- | --- |
| 4·23 | 지속하는 위키와 답의 재저장 | 원자료 문서·연결된 페이지·새 질문을 구분하고 한 개의 귀환 경로 사용 |
| 6 | raw/wiki와 전체에 적용되는 규칙 | 두 영역과 하단의 공통 규칙을 분리. 규칙을 세 번째 변환 단계로 그리지 않음 |
| 7 | 새 자료로 관련 페이지를 함께 갱신 | 문서 입력·대조·갱신 대상 목록. 여러 갈래 선이 카드 사이를 가로지르던 분기 제거 |
| 8 | 찾아 읽기·답하기·저장하기 | 큰 타이포의 세 역할과 한 개의 재사용 경로. 현재 문맥에 읽는 단계를 명시 |
| 10 | 장 메모·인물·주제·근거 | 읽은 사실과 인물의 자기 설명, 관련 주제/장 근거, 미확인을 다른 위계로 배치 |
| 14 | 고객의 요구와 회의 뒤 현재 상태 | 두 상담과 내보내기 상태를 병렬 정리하고 응대 질문으로 연결 |
| 16 | 공유 개념과 다른 기준 | 회귀·회귀트리의 제곱오차 합류와 분류트리 예의 Gini를 분리. 서로 같은 기준으로 합치지 않음 |
| 36 | 여러 기록을 새 질문에서 함께 읽기 | 세 기록을 열린 목록으로 묶고 큰 후속 질문으로 한 번 연결 |
| 37 | 결정의 대체와 보존 | D1→D2의 시간 흐름과 각 맥락·부담을 분리. 이전 결정을 삭제하는 인상 방지 |

색 테두리 박스는 제거하고, 원자료를 나타내는 문서 형태만 사용했다. 중립 선은 구분과 묶음, 화살촉은 방향, 색은 원자료·갱신·질문·변경 조건에 사용했다. 큰 글자와 실제 관계에 공간을 주고 캡션의 반복 문구는 한 문단으로 정리했다. 도식은 알고리즘의 정확성·실행 성공을 증명하는 그림으로 제시하지 않는다.

40장 구성·제목·대본·시간 배분·별도 학습 자료6개·사진은 유지했다. 세 사례의 가상 라벨·미확인·출시일 미확정, 코드/논문과 Node 보조 실습의 범위도 유지했다. 공통 렌더러·CSS·다른 발표를 바꾸지 않았다.

## 검수

- 실제 40장 PNG와 변경된10장을 직접 열어 새 구도를 확인했다. 본문 넘침·진단·이미지 실패·콘솔 오류는 없다.
- SVG9종의 실제 글자 경계와 글자끼리의 겹침을 검사했다. 7장의 두 줄 간격을 추가 조정한 뒤 경계 초과0·겹침0이다.
- 원고40·대본40·자료6·참조55·기본29장/1,080+120초와 심화 별도 경로를 대조했다. 20분은 배분안이며 실제 낭독 측정이 아니다.
- 실제 기본 경로·장내5링크·개요40장·발표자 양방향 이동,390px 읽기 전문/순서/18px/이미지contain·alt·가로 넘침 없음, 읽기 anchor18개를 확인했다.
- 전체 사이트 build/비수정 verify와 기존261/261 검사가 통과했다. 별도 주제 복사·이동 후38출력 파일도 바이트가 같다.
- 기존 demo25파일과 ZIP은 변경하지 않았다. 학습 자료6개의 원본도 변경하지 않았다.
