## 공통 조판 충돌과 최소 해결

초기 REMAKE_SPEC는17장 `현상p → blockquote → 지원p`가 기존 quote 조판으로 구현된다고 보았으나, 실제 `blocks.js`의 적합성 판정은 첫 본문이 blockquote인 경우만 허용했다. 원문대로 구현하면 document fallback이 되어 의도한 위계를 잃었다. A가 발견하고 B/매니저가 소스를 재확인한 뒤 root·디자인 매니저에 실제 원인·영향·최소 선택을 직접 전달했다. 이는 초기 명세의 실제 지원 조건 오가정이며 AGENTS/DESIGN 전체의 결함으로 단정하지 않는다. 후속 정책 검토자가 이번 제작 사실과 문구를 대조한다.

root/매니저 확정 후 **명시 `compose: quote`일 때만** 단일 인용 앞뒤에 짧은 일반 문단을 허용했다. 기존 인용220자·지원문단합계200자 한도와 단일 인용, 원순서를 유지한다. auto의 ‘첫 본문 인용’ 선택은 그대로다. 다중 인용·이미지·목록·긴 인용·긴 지원은 document로 보존한다. CSS·새 키·좌표·주제 전용 renderer·새 라이브러리는 없다. MARKDOWN-FIRST에 명시quote의 앞뒤 짧은 문단·원순서·fallback/자동 선택 유지 한 문장만 덧붙였다.

영향은 명시quote에 짧은 선행 문단을 둔 입력의 조판 선택이다. 기존 다른4덱33개 blocks 장의 조판은 HEAD의 planner와 동일함을 확인했다. root는 공통 변경 계약에 따라 다른 주제의 기존quote 대표, 긴 한국어·밝은 문서·읽기·모션 줄이기 대표를 실제 화면에서도 확인한다. 기존 CSS 재사용과 모션 테스트 성공은 해당 시각 확인을 대신하지 않는다.
