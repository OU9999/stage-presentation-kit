## 재사용할 작성 경로

[DESIGN](../../DESIGN.md#역할에서-시안으로-연결하기)에 역할·주역·정확한 구절/관계·자료 지위·보존·참고 원리·지원 경로·다음 검토자를 연결하는 짧은 인수 예를 추가했다. 실제 크기의 대안을 비교하고 무엇이 먼저 읽히고 어떤 오독이 줄었는지 선택 이유를 쓰도록 연결했다.

[Markdown 작성 안내](../../MARKDOWN-FIRST.md#역할을-유지하는-작은-레시피)는 두 판단/한 실행의 H2/H3, 공통 안내의 위치, 외부 SVG 내부 조판의 경계와 실제 링크를 작은 레시피로 설명한다. [검수 안내](../../DESIGN-REVIEW.md)는 기존 reason에 실제 시각 판단을 적는 예를 제공한다. 생성 프로젝트 README도 설치된 세 정본으로 직접 연결한다. 실제 현재 CLI init 산출물은 [README 복사](generated-README.md)와 [명령·SHA](scaffold-proof.json)에 보존했다. 이 별도 증명은 설치 전 README 생성 범위이며, 패키지 CLI 실행은 전체 테스트의 별도 범위다.

현재 프로젝트의 역할 계약은 [current-roles.json](../../talks/llm-wiki/qa/current-roles.json)이다. 원고/DOM 소속·강조/개행·실제 glyph·SVG contain과 무방향 관계를 검사한다. 모바일18에는 [별도 native 읽기 검사](../../scripts/llm-wiki-reading-qa.cjs)를 추가했다. 현재 입력 해시·정확한 읽기 manifest·실제 행/경계/크기가 없으면 통과하지 않는다. 발표 논리px와 읽기 CSS px를 혼합하지 않는다.
