# 시안의 원자료와 관계 읽기

이 시안은 발표팀이 작성한 설명용 주제 메모와 위키 예문을 편집한 것입니다. 실제 사용자의 관찰, 실행한 모델 출력, 정확도·속도·학습 효과를 검증한 성과가 아닙니다. 원문 정본은 [같은 예제 팩](../../../../../../talks/llm-wiki/assets/expanded-study.txt)이며, 기술 근거는 그 팩에 적힌 설계 글·논문·공식 문서에서 확인합니다.

## 다음 질문에 다시 쓰기

원자료를 보존하면서 자료의 개념과 관계를 문서로 정리해 현재 이해와 다음 질문에 다시 씁니다. 출발점은 ‘AI가 내 자료를 좀 더 잘 이해해 줬으면’이라는 필요입니다. 사람은 우리 스터디에서 왜 쓰고 어떤 질문에 다시 활용할지, 자료를 왜 골랐는지 직접 적습니다. 구성 예의 선택 이유는 실제 사용자의 직접 기록이 아닙니다.

원래 3장 도식의 개념과 비교는 각각 현재 이해와 연결됩니다. 현재 이해는 계획·다음 질문과 연결되고, 계획과 다음 질문 사이에도 관계가 있습니다. 이 다섯 선은 자동 갱신 방향이나 필수 생성 순서가 아닙니다. 이 전체 맥락은 첫 시안의 한 문장 뒤에서 발표자가 설명하며, 필요한 독자는 [정본 도식 설명](../assets/original-diagram-reading.md.txt)과 [보존한 원본](../../../../../../talks/llm-wiki/assets/expanded/knowledge-layers.svg)으로 돌아갑니다.

## 원자료와 정리한 이해

2장은 같은 팩의 15분 가상 조건과 그 조건을 읽은 답에서 두 구절만 발췌한 설명용 재구성입니다. 실제 도구 화면 캡처나 이번에 생성된 결과가 아닙니다. 시간표 전체를 다시 제시하지 않고, 원자료에 남은 조건과 위키 문서에 적은 선택의 한 대응만 읽습니다.

- 왼쪽은 `raw/study-retro.md — 나중에 추가`의 원문: ‘본편 뒤 별도 활동은 15분만 배정한다.’ 실제 참가자 조사나 수행 시간의 측정이 아닌 가상 조건입니다.
- 오른쪽은 `wiki/questions/first-study.md`의 원문: ‘이번 가상 조건에서는 새 도구 설치보다 기존 목차와 문서 연결을 읽는 것부터 시작한다.’ 같은 조건에서 무엇부터 할지 검토하도록 준비한 답의 예이며, 실행된 모델 출력이 아닙니다. 질문 페이지는 관련 개념·비교·현재 계획과 연결됩니다.
- raw에는 `context-note.md`·`retrieval-note.md`·`synthesis-note.md`를 보존합니다. 요지·선택 이유·남은 질문을 함께 읽습니다.
- wiki의 개념 문서는 여러 자료의 설명을, 비교·종합은 차이와 현재 계획을 담습니다. 질문·목차·로그는 답·탐색 경로·변화 이유를 남깁니다.
- `rules.md`는 두 영역에 함께 적용하는 작업 약속입니다. 원자료 보존, 근거 연결, 관련 문서 갱신, 중요한 결과 확인을 안내합니다. raw를 지우고 wiki로 대체하지 않습니다.

마크다운은 글과 링크를 적는 텍스트 파일입니다. 이 폴더 이름은 설명용 구성 예이며 모든 도구의 필수 규격이나 자동으로 읽히는 파일명을 뜻하지 않습니다. 약속 전체와 실제 예문은 [예제 팩](../../../../../../talks/llm-wiki/assets/expanded-study.txt)의 `rules.md` 절에서 읽습니다. [정본 5장 관계 설명](../assets/original-diagram-reading.md.txt)도 보존합니다.

## 요약과 기존 문서의 관계

3장은 Ingest의 한 관계망만 읽게 합니다. 같은 세 메모 ‘목적과 맥락’·‘검색과 비교’·‘지식의 활용’을 읽고 내용을 나눕니다. 자료 요약은 한 자료의 요지를 찾는 원자료의 입구입니다. 요약은 기존 개념·비교와 현재 계획 각각에 연결되고, 개념·비교와 현재 계획도 서로 연결됩니다.

세 선은 문서 사이의 관계입니다. 요약→개념→계획의 필수 생성 순서, 자동 양방향 갱신, 별도 그래프 DB의 필수 사용을 뜻하지 않습니다. 새 자료가 들어오면 관련 쪽을 찾아 새로 쓰거나 고치고, 바뀐 근거와 문서·목차·링크를 함께 확인합니다. 원자료와 사람이 남긴 선택 이유는 보존합니다.

입력 메모별 속성(목적·이유·결과 / 근거 검색·차이 / 종합·공유·검토)과 전체 관계는 [정본 10장 설명](../assets/original-diagram-reading.md.txt), [원본 도식](../../../../../../talks/llm-wiki/assets/expanded/ingest-map.svg), [예제 팩](../../../../../../talks/llm-wiki/assets/expanded-study.txt)에 보존합니다.
