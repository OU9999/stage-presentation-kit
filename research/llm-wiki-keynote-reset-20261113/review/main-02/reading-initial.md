- **390의 3/6/7/8/13/15:** 본문 이미지의 실제 폭은 318 CSS px / 원본 1440이다. 3의 선택 이유는 약 13.25px, 6의 정의는 12.37px, 7의 노드 13.25px와 관계 설명 8.39px, 8의 조건 14.13px·맥락 9.72px, 13의 할 일·남길 것 9.72px, 15의 근거 구절 11.48px로 계산된다. 수치는 원본 SVG 글자 크기 × 관측 image 폭/1440이며, 사람의 실물 판단을 대체하는 합격 하한이 아니다. 특히 13은 독자가 읽고 수행할 표 한 행이므로 단순 미리보기로 면제할 수 없다. 8의 선택 문구는 약 19px로 다른 자료보다 낫지만 입문 조건과 재구성 지위는 작고 준비된 팩의 조건은 해설에 있다. 원본 관계와 문서 표면은 유지하면서 읽기 전용 native 문장/표 또는 정확한 절 접근이 필요하다.
- **390의 10:** 18px 본문이 `감정 · 생각 · 판단 · 선택 이유를 직접` / `남깁니다.`의 두 실제 glyph 행이다. source에는 강제 개행이 없는 자동행이다. 사람의 책임을 말하는 문장에서 서술어만 떨어지므로 문장을 편집하거나 지원 문법의 의도 개행으로 책임·행동을 붙여야 한다. 글자 축소로 해결하지 않는다.
- **양폭의 11:** 원문·내 직접 기록·AI 해석의 지위를 한 표에 구분한 편집은 명료하고 넘침도 보이지 않는다. 그러나 필수 의미를 담은 표 8셀은 16px이며 일반 본문은 18px다. 필수 표를 작게 내린 현재 계약 문제를 교정해야 한다. 390의 `내가 직접 쓸 / 기록`, `15분만 / 배정한다.`도 표 폭 교정 후 실제 행으로 재검토한다.

## A와 직접 대조한 역할 차이

A는 발표 6이 2의 정의를 재진술하고, 15가 8의 선택을 되풀이해 구체로 엮은 이해와 검토할 주장 장면이 부족하다고 반려했다. B는 해설에는 정의·세 근거·15분 단독 인과 오독의 교정이 살아 있으므로 원자료/의미 부재와 구별해야 한다고 반론했다. A도 그 구분을 인수했다. 두 사람은 지원 내용의 존재가 발표 6/15의 판단 장면이나 모바일의 작은 자료를 자동 면책하지 않는다는 점에 합치했다. 발표 편집의 재설계는 A 범위, 읽기 재배치/정확 절 접근·10 호흡·11 표는 다음 구현 소유자의 행동이다.
