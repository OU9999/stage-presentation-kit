native3의 실제18px 행은390에서 `‘LLM Wiki와 RAG의 차이를 설명하고 다음` / `스터디의 진행안을 만들고 싶어서` / `이 메모를 골랐다.’`,1440에서 긴 앞구절 / `이 메모를 골랐다.’`이다. source의 유일한 시각 교정은 같은 인용P에 `이 메모를 골랐다` 앞 hardbreak1개이며 원문 단어·문장·자료 지위·18px·CSS·anchor를 보존했다. 별도 QA script/계약 변경은 새 실제 문단 회귀를 관측하는 코드이며 발표·읽기면을 다시 조판한 변경으로 오인하지 않았다.

읽기는 main03의 전40 직접 열람을 현재 대응 PNG와 전수SHA로 대조했다.1440전20과390의19는 완전히 같은 바이트이고,390의7만 bbox `(206,192,207,193)` 안 한 픽셀의 R61→60 차이다. 새7을 이전7과 직접 열어 작은 요약·큰 기존 문서·세 선·문구·글꼴 기하·링크에 영향이 없음을 확인했다. 양폭3/6/10/11/15/20의 새 대표12PNG도 직접 재독했다. 기존 전40 실제 열람의 동일 근거와 현재 영향·새 native를 구분하며, 새40전부를 직접 열었다거나 과거 승인 상태를 자동 승계했다고 기록하지 않는다.

작은SVG를 큰 독서 본문으로 취급하지 않았다. 자료 곁18px 링크가 정확한 공개 native절에 연결되고, 그 본문에서 선택 이유·동일 계획 전후·세 무방향 관계·전체 가상 조건·활동안·질문과 목적 원문을 실제로 읽을 수 있음을 결합해 판정했다. native1440의6/7 heading은 원본 픽셀에서 y30부터 ink가 시작해 잘림이 없고 실제 anchorY≈24와 부합한다.
