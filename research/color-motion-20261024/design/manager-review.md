# 디자인 매니저 검수

2026-10-24 · `/root/design_manager`

확정한 [컬러 사양](color-spec.md), [모션 사양](motion-spec.md), [취합](synthesis.md)과 [독립 프리뷰](preview.html)를 검수했다. 실제 제품의 코드·원고·WORK_LOG는 수정하지 않았다.

## 근거와 사양 대조

- 새 DevDay 원본의 범주·보라 이름·주황 선언·파랑 선택 막대 네 프레임을 매니저가 직접 열었다. 선명한 의미색과 중립 구조를 분리하는 방향에 부합한다. 영상 픽셀을 공식 HEX나 원본 모션 수치로 소개하지 않는다.
- 현행 `styles.css`의 `--slide-accent` 사용처를 정독했다. 명시적 강조·핵심 수치·범주색은 보존하고 eyebrow·섹션 자동선·비교 경계·장식 인용부호·단계 번호는 중립으로 분리한다. 구체 selector는 컬러 사양에 있다.
- 루트 적용 대상 6·7·8·9·12·19장의 실제 ID를 `content.js`와 대조했다. 런타임은 특정 ID나 문구를 인식하지 않고 공통 `slide.motion`을 사용하도록 인계한다.
- 두 디자이너가 직접 합의한 DOM·컨트롤 계약을 HTML/CSS/JS와 대조했다. 각자 독립 실무를 작성하고 상대 파일의 검토 결과를 직접 통지했다.

## 실제 브라우저 검수

ego-browser TaskSpace 2의 매니저 전용 p6에서 확인했다. 상세 값은 [브라우저 기록](evidence/browser-review.json), 시각 근거는 [데스크톱 차트](evidence/desktop-chart.png)와 [390px 범주](evidence/mobile-categories.png)다.

| 검사 | 관찰 결과 |
| --- | --- |
| 5개 장면 선택 | 선언·범주·이름·차트·단계가 각각 하나씩 활성화되고 선택 버튼과 내용이 일치. 데스크톱 가로 넘침 없음. |
| 적용 모션 | rise 280ms, 보조 60ms 지연; 범주 300ms에 0/60/120/180/240ms 지연; 차트 440ms에 0/40/80ms 지연; 단계 300ms에 0/60/120ms 지연을 실제 생성된 Animation에서 확인. |
| 차트 정보 | 42%·67%·91%가 처음부터 고정. 막대 회색 둘과 파랑 `rgb(36,168,255)` 하나. |
| 사용자 모션 끄기 | 같은 차트 내용·최종 막대가 보이며 생성된 animation 0. 다시 보기에도 정적 상태 유지. |
| 실행 중 OS reduce | 미디어 쿼리가 reduce로 바뀌고 CSS animation 0. JS의 body 플래그는 change 이벤트 처리 후 반영되며 CSS가 즉시 정적 표시를 보장. |
| 390px 화면 | scrollWidth 390px, nav 5개와 범주 5개 표시, 가로 넘침 0. 축소된 16:9 시안이며 긴 본문 읽기 UI의 검증은 아님. |
| 인쇄 에뮬레이션 | 5장면 모두 display flex·opacity 1·animation 0. |
| 재생 후 별도 라운드 | 차트 animation 0, 세 막대 transform none·최종 폭이 남는 것을 확인. |

공유 브라우저의 같은 자동화 라운드에서 animation.currentTime이 0에 머물러 자연 종료 대기 한 번이 타임아웃했다. 이후 별도 라운드에서는 효과가 종료되고 최종 폭·transform이 정상임을 확인했다. 타이밍 설정·정적 대안 검수와 실제 프레임 진행의 제한을 구분하며, 제품 구현 후 총괄이 전경 탭에서 재생·종료를 다시 확인한다.

모션 실무자의 별도 p7 검수도 타이밍·선택 막대·모션 끄기·reduce·인쇄·390px 결과와 일치했다. 해당 실무자는 nav에서 Home/End 전환, 체크박스 포커스 중 단축키 비개입도 확인했다. 매니저는 이 키보드 검수를 별도로 반복하지 않았다.

## 인계 범위와 한계

새 외부 의존성 없이 CSS 다섯 선택지와 작은 JS 접근성 분기로 구현할 수 있는 사양이다. 제품에 새 재생 UI를 추가할 필요는 없다. 프리뷰는 자체 문구·도형·가상 데이터만 사용하며 원본 사진·로고를 제품 자산으로 포함하지 않았다.

이번 검수는 디자인 프리뷰에 한정한다. 제품의 19개 양식·편집·내보내기·발표자 동기화·실제 PDF·물리 기기 검증은 후속 구현 단계에서 수행한다. 운영 상태와 담당자·다음 행동의 단일 기록은 루트 `WORK_LOG.md`다.
