# 바로 쓰는 시각자료 스타터

[발표 열기](index.html) · [같은 원본의 표](data.html) · [수정 원본 content.js](content.js)

이 폴더의 `index.html`을 열고 `content.js`의 문장과 숫자를 바꾼 뒤 새로고침합니다. 패키지 설치·Node.js·빌드·SVG 편집이 필요하지 않습니다. 7점 비율 추세·5범주 구성비·2단계 흐름은 각각 독립적인 `visual` 입력입니다. 코호트·인터뷰·가상 프로젝트 전체 스키마를 넣지 않습니다.

다른 발표에 쓸 때는 이 `content.js`의 장 하나를 복사합니다. `labels`와 `values`는 같은 순서·개수로 작성합니다. 비율을 직접 계산할 때만 `numerators`와 `denominators`를 함께 넣습니다. 값과 분자/분모를 동시에 넣지 않습니다. 없는 관측값은 `null`, 실제 0은 `0`입니다.

`focus`는 강조할 항목의 0부터 시작하는 위치이고 큰 숫자는 그 항목에서 계산합니다. `heroValue` 같은 숫자 사본을 작성하지 않습니다. 비율의 합계는 원래 분자·분모로 계산하고 반올림한 주별 비율을 평균하지 마세요.

화면에서 **내용 편집 → 시각자료 데이터 편집**을 열어 JSON을 바꿀 수도 있습니다. 적용하면 발표의 그림·강조값·읽기 표가 함께 바뀌고 이 브라우저에 저장됩니다. 잘못된 JSON이나 맞지 않는 배열은 적용 전에 진단합니다. **내용 내보내기**로 받은 `content.js`를 이 폴더의 같은 파일로 교체하면 다른 기기에서도 재생합니다.

별도 `data.html`은 이 폴더에 보관한 `content.js`를 직접 읽습니다. 브라우저의 임시 저장값을 다른 창에 자동 공유하지 않습니다. 별도 표에도 편집 결과를 반영하려면 내보낸 파일로 `content.js`를 교체하고 표 페이지를 새로고침합니다. 발표 안 읽기 모드의 표는 현재 편집값을 바로 사용합니다.

이 폴더 전체를 원하는 위치에 복사하고 `index.html`을 엽니다. `runtime/`에 필요한 공통 CSS·JavaScript가 들어 있어 저장소 밖의 새 폴더에서도 `file://`로 동작합니다. `content.js`만 수정하며 runtime 파일을 주제마다 고치지 않습니다.

지원 종류와 예시는 저장소의 `CONFIG.md` 중 ‘시각자료 visual’ 절을 확인하세요. 공통 렌더러나 제목 양식을 주제별로 고칠 필요는 없습니다.

발표 상단의 **표**는 현재 편집 중인 자료를 읽기 모드의 표로 엽니다. 별도 `data.html`은 파일에 보관한 원본을 확인하는 페이지입니다.
