# 글과 근거가 만나는 자리

[8장 열기](index.html) · [직접 수정할 content.js](content.js) · [같은 자료의 표](data.html)

이 폴더 전체를 복사하고 `index.html`을 엽니다. `content.js` 하나에서 문장과 자료를 바꾼 뒤 새로고침하면 됩니다. 설치·빌드가 필요 없고 `runtime/`의 공통 파일을 함께 옮기면 저장소 밖에서도 실행합니다.

| 장면 | 이미 있는 설정으로 재사용 |
| --- | --- |
| 집중 선언 | `layout:"cover"` 또는 `statement`. title 배열은 직접 정한 줄바꿈, `align:"center"`는 중앙정렬을 유지합니다. |
| 넓은 추세 | `layout:"visual"`, `visual.composition:"wide"`. 제목과 수치 열의 폭을 분리하고 차트를 전폭으로 펼칩니다. |
| 설명과 비교 | `visual.composition:"split"`. 왼쪽 글, 오른쪽 수치/레이블/차트를 같은 시작선에 묶습니다. |
| 정의와 긴 본문 | `layout:"statement"`의 `title`→`support`→`subtitle`에 주장·정의·본문을 넣습니다. 두 설명 블록이 있으면 본문용 글 크기와 행간을 씁니다. |

큰 숫자와 단위가 해당 열보다 길면 실제 폭에 따라 독립 행을 확보합니다. 원문이나 숫자를 약어로 바꾸지 않습니다. 모바일은 글→수치→그림→상세 표로 읽으며, 아주 긴 숫자의 글 크기만 필요한 범위에서 조정합니다. 한 화면에 담기 어려운 긴 원문은 읽기 모드에서 이어 볼 수 있습니다.

화면의 **내용 편집**으로 문장을 고치고, 시각자료는 **시각자료 데이터 편집**에서 바꿉니다. 수정 후 크기를 바꿔도 편집한 글을 다시 생성해 덮지 않습니다. **내용 내보내기**로 내려받은 `content.js`를 이 폴더의 파일과 교체해 보관합니다. 상단 **표**는 현재 편집값, 별도 `data.html`은 디스크 원본을 표시합니다.

예제는 가상 자료입니다. 앞4장은 기존 제품 개선 이야기의 같은 원고·값을 사용하고, 뒤4장은 긴 한국어·다른 주제7주·긴 숫자의 좌우/전폭 반례입니다. 회사별 로고·서체·슬라이드 자산을 복제하지 않은 독자 배치입니다.
