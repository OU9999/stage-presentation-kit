# 첫 경험을, 다음 행동으로.

[발표 열기](index.html) · [같은 자료의 표](data.html) · [직접 수정할 content.js](content.js) · [더 작은 스타터](../visual-starter/index.html)

수정 원본은 `content.js`입니다. 파일을 바꾸고 `index.html`을 새로고침하면 됩니다. Node.js·패키지 설치·빌드·SVG 편집은 필요하지 않습니다. 여덟 종류의 시각자료는 native DOM/SVG로 표시되어 사진용 사각 프레임을 사용하지 않습니다.

이 예제는 12주 가상 제품 개선 이야기이며 실제 회사의 성과나 인과 효과가 아닙니다. 기준·후반의 가입 코호트, 별도 인터뷰, 기획 점수·일정·투입과 후속 계획의 의미를 각 장의 설명·노트에서 구분합니다. 12장은 이 예제의 이야기 길이이며 다른 발표에 요구되는 제한이 아닙니다.

`content.js` 위쪽의 공유 정수와 배열에서 서로 연결된 장의 값을 계산합니다. 단독 장은 [독립 실행 스타터](../visual-starter/README.md)의 장을 복사하고 `labels`·`values` 또는 `items`에 필요한 자료를 넣어 만듭니다. 이 예제의 `weekly` 같은 공유 변수를 참조하는 장을 옮길 때는 해당 변수 선언도 함께 옮깁니다. 7점 추세·5범주·2단계 흐름의 스타터는 각 장이 독립적으로 동작합니다.

```js
{
  layout: "visual", title: "다음 질문을 고릅니다.",
  visual: { kind: "bars", labels: ["첫 주", "둘째 주", "셋째 주"],
    values: [12, 18, 9], unit: "건", focus: 1, emphasis: "focus" }
}
```

큰 숫자는 `focus`가 가리키는 자료에서 자동으로 나옵니다. 별도 `heroValue`나 SVG 안의 수치를 따로 유지하지 않습니다. 없는 관측값은 `null`, 실제 영은 `0`으로 적습니다. 직접 값과 분자/분모 비율 입력 중 한 방식을 고르며, 필요한 숫자·배열 대응·분모·참조 오류는 적용 전에 알려줍니다.

**내용 편집 → 시각자료 데이터 편집**에서 JSON을 바꿀 수도 있습니다. 적용하면 발표의 그림·강조값·읽기 표가 함께 바뀌고 현재 브라우저에 저장됩니다. **내용 내보내기**로 받은 `content.js`를 이 폴더의 같은 파일로 교체해 보관·전달합니다.

별도 `data.html`은 디스크의 같은 `content.js`를 직접 읽습니다. 브라우저의 임시 편집값을 다른 창에 자동 공유하지 않습니다. 별도 표에도 편집 결과를 반영하려면 내보낸 파일로 교체한 뒤 표 페이지를 새로고침하세요. 발표 안 읽기 표는 현재 편집값을 바로 사용합니다. 표의 행·열과 native 문구는 작은 화면에서도 읽을 수 있게 표시됩니다.

이 예제는 저장소의 공통 runtime을 상대 참조합니다. 저장소 전체를 함께 옮기거나, 어디든 폴더째 옮기는 목적이면 [runtime이 포함된 스타터](../visual-starter/)를 사용합니다. 주제마다 HTML·렌더러·CSS를 수정하지 않습니다. 선택형 Markdown 작성은 다른 다섯 예제에서 계속 지원하며 이 직접 원본을 덮어쓰지 않습니다.

발표 상단의 **표**는 현재 편집 중인 자료를 읽기 모드의 표로 엽니다. 별도 `data.html`은 파일에 보관한 원본을 확인하는 페이지입니다.
