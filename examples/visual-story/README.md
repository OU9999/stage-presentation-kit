# 첫 경험을, 다음 행동으로.

가상 제품 개선 프로젝트를 12장·아홉 가지 표현으로 보여주는 데이터 발표 예제입니다. 실제 회사의 성과나 인과 효과가 아닙니다.

[발표 열기](index.html) · [데이터·계산·읽을 수 있는 표](data.html) · [입력 data.json](data.json) · [생성된 원고](slides.md) · [PDF](../../output/pdf/visual-story.pdf)

[12장 전체 미리보기](../previews/visual-story-overview.png) · [네 가지 시각자료 모음](../previews/visual-story.png)

수정 원본은 **data.json 하나**입니다. 주별 정수·퍼널 중간 인원·인터뷰 분류·기획 판단·일정·투입을 바꾸면 기간 합계와 비율, SVG, 표, 발표의 숫자를 함께 계산합니다. `slides.md`, `assets/*.svg`, `data.html`, `content.js`, `index.html`은 생성 결과입니다. 이 파일의 숫자를 따로 손으로 고치면 다음 생성 때 덮어씁니다.

저장소 루트에서 실행합니다. Node.js만 필요하며 패키지 설치나 AI 연결은 필요하지 않습니다.

```sh
node scripts/build-visual-story.cjs

# 기존 다섯 예제와 이 데이터 예제를 한 번에 갱신
node scripts/build-examples.cjs

# 별도 입력으로 같은 구조의 발표 만들기
node scripts/build-visual-story.cjs path/to/data.json path/to/output
```

별도 출력의 입력·가이드·갤러리 링크는 실제 파일까지의 상대 경로로 생성합니다. 생성기는 입력 파일을 덮어쓰거나 다른 경로로 복사하지 않습니다. 렌더러는 저장소의 공통 `app.js`, `styles.css`, `deck-model.js`를 상대 참조하므로 공유할 때는 입력·출력과 저장소의 상대 위치를 함께 유지하세요. 기본 예제는 저장소 전체를 옮기면 됩니다. 생성 후에는 `file://`로 오프라인 재생할 수 있습니다.

`data.json`은 현재 SVG가 지원하는 12주·세 기간·네 퍼널 단계·네 인터뷰 분류·네 개선안·세 투입 역할 구조를 사용합니다. 지원하는 관찰창은 7일, 표시 자릿수는 소수 첫째 자리입니다. 각 주 신규 가입·단계 분모·인터뷰 분모와 기준 활성 인원은 양수이며 활성 인원은 신규 가입을 넘지 않아야 합니다. 활성·개별 인터뷰 분류·개별 투입 셀의 0은 허용하지만 투입 전체 합계는 양수여야 합니다. 개별 투입은 0–999인·주 범위입니다. 같은 좌표의 우선순위 항목은 겹침을 막기 위해 오류로 안내합니다. 비율 끝값을 따로 입력하지 않습니다. 일정은 시작·종료 주를 모두 포함하며 투입 단위 인·주는 경과 주수와 다릅니다. 잘못된 입력은 필드 경로와 수정 이유를 안내하고 이전 생성물을 보존합니다.

제목·한 줄 메시지는 native 텍스트이고 복잡한 그림 여덟 개는 로컬 SVG입니다. 작은 화면에서는 SVG 내부 글씨가 작아질 수 있으므로 발표 상단의 **표** 링크, 도움말 또는 마지막 장에서 [동일 원본의 실제 HTML 표](data.html)를 열어 정확한 값·분모·관계·계산을 읽으세요. 표는 모바일에서 가로 스크롤하며 모든 셀을 보존합니다.

화면 편집은 native 문구의 발표용 복사본을 브라우저에 저장하고 `content.js`로 내보냅니다. SVG 안 숫자·표·입력 `data.json`으로 돌아오지 않습니다. 수치·관계를 오래 보관할 수정은 `data.json`에 반영해 다시 생성하세요. 숫자가 들어간 문장도 함께 바꾸려면 [authoring.cjs](../../scripts/visual-story/authoring.cjs)의 데이터 기반 문구를 수정합니다.

PDF와 미리보기 이미지는 생성 명령이 갱신하지 않습니다. 최종 발표에서 다시 저장하며 데이터 표와 실제 숫자가 같은지 확인합니다.
