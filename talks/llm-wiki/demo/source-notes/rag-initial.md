# RAG 최초 읽기 메모

- 자료 ID: S-RAG-INITIAL
- 원문: https://arxiv.org/html/2005.11401v4
- 읽은 위치: §2.3 Generator만
- 형식: 발표자가 구성한 최초 읽기 메모. 원문 전문이 아님

검색한 문서와 입력을 이어 생성기에 넣는다. 이 메모만으로 §2.4의 학습 방식은 판단하지 않는다.

이 메모는 보존하고, 더 읽은 내용은 [확장 읽기 메모](rag.md)에 별도 기록한다. 최초 메모와 확장 메모는 같은 논문의 서로 다른 읽기 범위이며 논문 자체가 바뀐 사례가 아니다.
