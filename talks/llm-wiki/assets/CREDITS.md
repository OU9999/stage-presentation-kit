# LLM Wiki 발표의 시각 자료와 예제

현재 판은 48장·본편35분·Q&A5분 구성입니다. 도식과 문서 화면은 이 저장소에서 직접 제작한 설명용 구성입니다. 외부 강의 슬라이드·인물·브랜드 이미지·앱 로고를 발표 자산으로 사용하지 않습니다.

## 현재 도식

`expanded/`의 SVG 19종은 검정 Stage 무대에서 개념·비교·변화를 읽도록 제작했습니다. 추상 관계도는 열린 무대를 사용하고, 읽어야 하는 문서 내용만 별도 문서 면으로 구분합니다. 공통 조형 기준은 [STAGE 디자인 가이드](../../../DESIGN.md), 제작 소스와 이번 검토는 [DevDay 스타일 교정 기록](../../../research/llm-wiki-devday-20261031/)에 있습니다.

| 파일 | 설명 역할 |
| --- | --- |
| `knowledge-layers.svg` | 보존한 원자료와 연결된 이해 |
| `rag-path.svg` · `wiki-path.svg` | 같은 자료와 질문의 검색·지속 문서 비교 |
| `agentic-routing.svg` | 근거를 찾을 곳과 반복 판단 |

| `ingest-map.svg` | 요약·개념·비교·현재 계획 연결 |
| `source-concept.svg` | 자료별 요약과 주제별 개념의 차이 |
| `comparison-synthesis.svg` | 비교에서 현재 계획으로의 종합 |

## 예제의 범위

주제별 메모·위키 문장·모임 조건·활동안은 개념을 설명하기 위한 구성입니다. 실제 모델 출력·자동 실행·모임 성과를 기록한 것이 아닙니다. 개념의 설계 기원과 기술 근거는 [원문 안내](../materials/reference-library.md)에서 구별합니다.

이전 사진·도식·데모는 변경하지 않았습니다. 해당 판의 사진 사용 조건·원출처 관찰·제작 기록은 [이전 자산 출처 기록](../../../research/llm-wiki-devday-20261031/evidence/CREDITS.before.md)에 보존합니다.
