# 팀의 학습을 남기는 방법

발표 때 한 번 읽은 기록을 다음 사람이 다시 사용할 수 있게 만듭니다.

이 자료는 내부 학습 흐름을 설명하기 위한 가상 예시입니다.

---

# 한 장면과 여러 질문을 남깁니다

![자체 제작한 가상 보고서](../../assets/examples/report.svg)

- **무엇을 알았는지** 짧게 적습니다.
- 모르는 것은 `확인할 질문`으로 남깁니다.
- 이미지와 목록을 원고 순서대로 함께 읽습니다.

---

# 읽는 사람에게 맥락을 줍니다

## 회의가 끝나도 남는 정보

| 항목 | 기록할 내용 |
| --- | --- |
| 질문 | 이번에 알고 싶은 것 |
| 관찰 | 실제로 보거나 들은 내용 |
| 결정 | 다음에 확인할 작은 행동 |

빈 칸은 가상의 값으로 채우지 않습니다.

---

# 설명에 필요한 코드는 그대로 둡니다

```text
질문 → 관찰 → 결정
구분선은 다음 문자열 안에 있습니다.
---
원문과 줄바꿈을 그대로 읽습니다.
```

일반 코드 블록은 이미지로 바꾸지 않아도 됩니다.

---

# 함께 읽는 시간이 기록을 다듬습니다

> 다음 사람이 이해할 수 있을 만큼,
> 지금 알고 있는 것을 적습니다.

가상 워크숍의 안내 문장입니다.

긴 설명은 읽기 화면에서 전체 내용을 확인하고 발표가 넘치면 원고를 직접 나눕니다.
