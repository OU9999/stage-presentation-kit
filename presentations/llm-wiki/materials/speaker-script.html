40장 대본 · 본질과 세 사례의 20분 진행

정의·등장 동기·LLM 작성과 유지, 세 적용 예와 선택 심화의 장별 발언

기본 진행은 **1~28장 연속: 설명·참여1,080초(18분) → 40장 Q&A120초(2분)**입니다. 29~39장은 선택 심화이며 모두 열면555초가 별도로 추가됩니다. 시간은 준비한 배분안이며 실제 낭독·사람 반응을 측정하지 않았습니다.

정의→반복 재종합 문제→저장되는 개념·비교·종합→LLM의 작성·유지와 사람의 탐색→구조·ingest/query/lint→독서·고객 요구·강의 메모 순서로 진행합니다. 세 사례의 입력·파일·응답은 가상 자료로 만든 적용 예입니다. 공개 구현 관찰·논문 실험·기존 고정 교정 데모는 심화에서 범위를 구별합니다.

발표 이동과 읽기 링크

핵심은1→2→…→28→40입니다.28장 안의 **‘질문과 적용 이야기’**를 눌러40장으로 이동합니다.40장에는29장 ‘공개 구현과 실험 더 보기’와34장 ‘기존 파일 교정 예제’로 들어가는 실제 전환 링크가 있습니다.34/39장의 ‘질문으로 돌아가기’는40장으로 갑니다. 자료의 ../slides.md#N 링크는 별도 읽기 화면을 여는 참고 경로입니다. O 개요는 예비 이동 수단입니다.

13장은 동등한 두 상담을 읽고5초 생각하며, 구분 이유는14/15장에서 회수합니다.24장은 자기 노트 작성20초와 선택 공유를 포함합니다. 웹 투표·자동 집계·입력 저장 기능은 없습니다.

말하기

“이번에 읽은 자료를 다음 질문에서도 함께 쓸 수 있을까요? 답 한 문장보다, 여러 자료에서 무엇을 비교하고 어떻게 연결했는지를 떠올려 보세요. 오늘은 그 정리를 LLM이 쓰고 계속 갱신하는 방식을 보겠습니다.”

진행: 사진과 큰 질문을 짚고 2초 둔다.

전환: “먼저 LLM Wiki가 무엇인지 한 문장으로 보죠.”

2장 · LLM이 쓰고 계속 갱신하는 지식 위키

읽기 2장 · 핵심 · 00:20~00:55 · 35초

말하기

“LLM Wiki는 LLM이 원자료 사이의 개념과 비교, 연결을 Markdown 위키로 작성하고 계속 갱신하는 지식관리 방식입니다. 다음 질문이 이전 정리에서 출발하게 하려는 설계입니다. Karpathy가 공개한 아이디어를 풀어 쓴 설명이며 특정 완제품의 이름이나 공인된 표준은 아닙니다.”

진행: 정의를 한 번 읽고 개념·비교·종합 세 단어를 짚는다.

전환: “이 방식이 풀려는 반복은 무엇일까요?”

다음 핵심: 3장. 다음 장으로 진행합니다.

3장 · 같은 자료를 매번 다시 엮고 있다면

읽기 3장 · 핵심 · 00:55~01:35 · 40초

말하기
