LLM Wiki · 자료가 지식으로 쌓이는 방식

48장 대본 · 본편 35분과 Q&A 5분

필요·RAG와 비교·실제 작동·활용과 첫 시도의 기승전결을 잇는 발언과 진행 안내

1~47장 본편은 35분, 48장 Q&A는 5분의 배분안입니다. 실제 음성 리허설을 측정한 시간은 아닙니다. 1→2→…→48장으로 진행합니다.

기승전결은 기 5분: 필요 → 승 8분: RAG와 비교 → 전 14분: 위키 작동 → 결 8분: 활용·판단·첫 시도입니다. 세 영상의 원문 자막과 개념 슬라이드·시연을 역할별로 재검토했습니다. 추가 공동 세미나는 별도 발표 전문가 두 명이 전체 자막을 각각 읽고 직접 협의한 계약을 반영했습니다. 연속 음성을 완주했다는 의미는 아닙니다. 기술 일반화는 일차 자료와 대조했습니다.

10~41장의 스터디 파일과 질문·답·한 쪽 진행안은 발표팀이 작성한 설명용 구성 예입니다. 세 영상의 읽기 메모는 실제 원문을 요약했고 새 모임 조건은 가상으로 정했습니다. 실제 모임 성과·자동 에이전트 실행·정확도 비교 결과로 소개하지 않습니다. 40장의 실제 활동안은 사전 준비된 공개 팩을 읽는 15분 활동이며 설치나 모델 생성 완료 시간은 아닙니다. 개인 기록·회고의 상세는 학습서에 보존합니다.
