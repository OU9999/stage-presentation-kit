LLM Wiki · 자료가 지식으로 쌓이는 방식

LLM Wiki 학습 자료

세 영상에서 출발해 연결·축적·갱신·재사용을 배우는 48장 발표의 학습 자료

LLM이 자료 사이의 관계를 문서로 남기고, 다음 질문에서 다시 읽고 고칩니다. 이번 발표는 세 영상의 목적·지식 연결·검색·실제 작업 흐름을 따라 LLM Wiki의 특징과 RAG와의 관계를 설명합니다.

지금 필요한 자료

원하는 일 읽을 자료 가져갈 결과
개념과 작동을 충분히 이해하기 혼자 공부하기 연결·지속 문서·다중 갱신·재사용과 세 작업
세 영상으로 작은 위키 만들기 실습과 해설 · 새 복사용 팩 개념·비교·계획을 만들고 후속 질문에 쓰는 순환
35분 발표 진행하기 48장 대본 기승전결과 본편 35분·Q&A 5분 진행안
영상과 기술 근거 확인하기 원문과 근거 실제 발언·우리 해석·기술적 교정의 구분
실제 활동안 한 쪽 읽기 15분 스터디 진행안 준비된 팩에서 선택한 두 메모로 관계·근거·다음 질문 확인
기존 정밀 교정 재현하기 고정 교정 기록 · ZIP 승인안을 파일에 적용하는 별도 심화

발표에서 실습으로

새 발표는 1~48장 순서대로 진행합니다. 기 1~8장 5분, 승 9~19장 8분, 전 20~36장 14분, 결 37~47장 8분, 48장 Q&A 5분의 배분안입니다. 실제 음성 리허설 시간을 측정한 결과는 아닙니다.

45장에서 자기 질문을 적고 46장에서 시작 요청을 봅니다. 발표 후에는 기본 실습으로 옮겨 목적 하나·실제 영상 메모 세 개·연결된 계획·후속 질문 하나를 만들어 보세요. 자료의 장 링크는 별도 읽기 화면을 엽니다.

이번 예제의 흐름

처음에는 ‘다음 AI 스터디에서 LLM Wiki를 어떻게 시도할까?’를 묻습니다. 세 영상의 읽기 메모를 넣고 자료 요약·개념·비교·현재 계획을 연결합니다. 나중에 입문자와 15분 실습이라는 가상 조건을 더해 관련 여러 페이지를 갱신합니다. ‘입문자와 15분 활동은 무엇부터 할까?’라는 후속 질문은 그 페이지들을 다시 읽고 시작합니다.

새 조건이 LLM Wiki의 보편 정의를 바꾸는 것은 아닙니다. 개념의 우리 적용 범위, 비교의 선택 기준, 종합의 현재 계획이 구체화됩니다. 유용한 답은 검토 뒤 저장하고, 그 정리를 읽어 실제 15분 진행안을 만듭니다. 시간·출처·작성 주체·미확인 조건을 대조하고 결과와 선택 이유를 다시 연결합니다. 활동에서는 전체 세 메모 중 목적·연결을 설명한 첫 메모와 사람 입력·산출물·검토를 설명한 공동 세미나 메모를 골라 읽습니다.

자료를 읽는 세 가지 구분

  • 실제 외부 자료: 사용자 제공 두 YouTube 영상, Karpathy 설계 글, 논문과 공식 문서. 전체 자막·대표 화면의 확인 범위.
  • 설명용 구성 예: 발표팀이 작성한 읽기 메모·위키·계획·후속 질문 답과 가상 모임 조건. 이번 세션의 모델 출력이나 실제 스터디 성과가 아닙니다.
  • 고정 교정 실행: 기존 ZIP의 승인안을 Node로 적용·검사한 기록. 실제 LLM이 새 답을 만든 실험과 구분합니다.

구판 예제와 다른 주제

이전 RAG·LoRA 학습 팩은 문맥·문서·모델 학습의 경계를 연습하는 구판 부록으로 보존했습니다. 새 48장 본편을 따라갈 때는 세 영상 학습 팩을 기준으로 읽으세요.

기존 독서·고객 요구·강의 메모는 가상 적용 예입니다. 새 흐름을 익힌 뒤 자신의 자료로 바꿔 볼 때 참고할 수 있습니다.
