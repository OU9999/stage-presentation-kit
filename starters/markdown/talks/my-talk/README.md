# 이 원고 사용하기

수정할 파일은 slides.md입니다. 사진·첨부는 assets 안에 있으며 다른 발표나 공용 assets에 의존하지 않습니다. 폴더 전체를 kit의 talks 아래에 새 이름으로 복사하면 새 발표가 됩니다.

원고6장은 큰 문장·세로3사진·H2 혼합5자료·목록 아이콘월5개·함께 읽기·맺음의 예시입니다. 본문과 사진 경로는 Markdown에 한 번만 작성합니다. stage-slide/group은 배치·색·사진 초점을 고르는 선택 설정입니다. 자세한 작성법은 kit의 MARKDOWN-FIRST.md를 참고하세요.

자료를 바꿀 때 alt·사진 title caption과 출처도 함께 고칩니다. 기본 사진 fit은 원고에서 cover를 선택했으며, 중요한 장면이 남는지는 실제 미리보기에서 확인하세요. 읽기에서는 원본 사진 전체를 보여 줍니다. 숫자3개는 가상 모임의 질문 계획이고 측정 성과가 아닙니다.
